# Setup Authoring Contract

## Setup Contract Frame

Establish from evidence:

- the exact future target path, Rule or Skill semantic type, and target owner;
- the target-repository evidence the setup controller must inspect and supply to the Author;
- every target obligation whose value can change behavior, including preservation and non-goals;
- the paths the author may write and the surfaces it must validate;
- the conditions that select one target outcome; and
- the exact material ambiguity, missing authority, or unsupported fact that stops generation.

Describe required target meaning without imposing an outline or unsupported authoring order. Let
the setup controller discover project facts in the target repository and include every fact the
tool-free Author needs in its Context Packet. Preserve supported existing target semantics unless
accepted intent explicitly changes or retires them.
