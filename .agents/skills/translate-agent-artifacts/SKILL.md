# Translate Agent Artifacts

Update the required Simplified-Chinese documentation mirrors after English Rule or Skill authoring.

## Translate the final source

Discover and read the applicable project documentation and translation policy by concern, without
assuming a Rule identifier or path. Obtain from its owner the frozen complete affected set of final
English sources and required mirrors. Read each source and its mapped mirror when present; create a
missing required mirror in the same affected-set update. Apply the loaded policy's source-authority,
mapping, fidelity, structure, and wording-aid boundaries.

If an English source is ambiguous or incomplete, stop and return the uncertainty to its English
owner rather than resolving it in translation. Otherwise update the complete mapped mirror set
once. Finish when every selected source has its policy-required updated mirror, and report changed
paths and any unresolved source uncertainty.
