## Codex coding and writing

**Code.** Make the smallest complete change. Reuse validation at its owning boundary and rely on invariants established by types or upstream checks. Add a guard, retry, or fallback only for a reachable failure that this layer owns. Surface errors through the existing contract.

**Writing.** State the relevant fact directly. Write comments, titles, and summaries about the current code or result. Include qualifications only when they affect accuracy, interpretation, or the reader's next action.
