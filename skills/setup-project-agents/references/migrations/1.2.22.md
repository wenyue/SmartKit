# CodeGraph readiness and Copilot project MCP adapters

**Release: 1.2.22.** Previously initialized projects may lack the local CodeGraph readiness now required by full setup. Their Copilot Project MCP adapters may still use VS Code's configuration path and interpolation syntax.

Run full setup once with this release or later, applying any earlier selected migrations in the same session:

- Prepare and verify CodeGraph for the target working tree through setup's public preparation route before starting the frozen session. Preserve existing index data and independent host configuration; SmartKit's plugin owns the CodeGraph MCP declaration.
- For projects declaring Copilot Project MCP servers, regenerate their adapters from canonical project configuration into `.mcp.json` under `mcpServers`, including Copilot environment interpolation and resolved workspace paths. Let setup retire only its recorded fields from `.vscode/mcp.json`; preserve independently owned fields and resolve reported ownership or destination conflicts before retrying.

Completion requires verified local CodeGraph readiness, configuration convergence and successful full setup cleanup. Let `finish` record the resulting `setupVersion`; the recorded version alone is not runtime readiness evidence for another user or session.
