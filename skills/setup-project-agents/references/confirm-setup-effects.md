# Confirm setup effects

Use this reference only when the requested Setup scope leaves a necessary effect unauthorized. Ask about the exact action, the target it affects, and any prerequisite it needs. For CodeGraph, identify what must be installed, indexed, or started in the active harness and project. For OpenWiki, identify the actual Git root and writes needed there, especially when it differs from the project directory. Reuse authority already given for the same effect and target.

## Prompt

> To continue setting up `<project>`, I need to <specific action> in `<target>`. This will <immediate effect>.
>
> Should I proceed with that step?

Wait for an answer before performing the effect. If the user declines, report what is pending and the evidence or completed work they can retain.
