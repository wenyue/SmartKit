# Document Target Changes

## Establish affected references

Before moving, renaming, or deleting a document, inspect incoming links across the documentation scope established by the task and project. Include fragments and equivalent path forms under project resolution rules. Inspect the same impact before judging completion in review. If required documents or reference evidence are unavailable, report the gap and pause the dependent change or conclusion.

## Handle the destination

| Change | Required treatment |
| --- | --- |
| Move or rename | Update affected links to the destination and confirm that fragments still identify intended content. |
| Delete | Redirect to an inspected replacement that supports the link's meaning; otherwise remove or revise the dependent reference within authorized scope. |

If a necessary repair exceeds scope, stop the dependent target change and identify the required authority. A requested review records unresolved repair without editing.

## Verify completion

Check affected incoming links after the change. For a moved document, also check internal links whose relative paths may resolve differently. Every affected reference in the established scope must resolve; report that scope with the result.
