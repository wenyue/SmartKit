# Document Target Changes

Before a target document moves, is renamed, or is deleted, inspect incoming links across the
documentation scope established by the task and project. Include links to its fragments and use
the project's resolution rules to find equivalent path forms. In review, inspect that same impact
before judging whether the target change is complete. If the required documents or reference
evidence are unavailable, report the gap and pause the dependent change or conclusion.

For a move or rename, update affected links to the destination and confirm that their fragments
still identify the intended content. For a deletion, redirect a link only when an inspected
replacement supports its meaning; otherwise remove or revise the dependent reference within the
authorized scope. If a necessary repair exceeds that scope, stop the dependent target change and
identify the required authority. A requested review records the unresolved repair without editing.

Verify affected incoming links after the change, and check links inside a moved document whose
relative paths may now resolve differently. Completion requires every affected reference in the
established scope to be resolved; report that scope so the result does not imply coverage beyond it.
