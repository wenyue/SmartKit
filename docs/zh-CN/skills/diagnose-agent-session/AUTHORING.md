# 编写决策

## 区分采集失败与会话诊断

本地 Codex 快照与 Tokscale 观测的时间区间、效果和失败方式不同。独立保留各自的部分证据：提供程序超时不能证明会话卡住，整个会话的 token 总量也不能替代缺失的行为或轮次费用证据。将它们合并成一个健康标志会产生没有依据的结论。

## 只排除已识别的采集调用

保留新的随机采集 ID 和恰好匹配一次的规则。历史诊断调用是真实的会话活动；宽泛地匹配命令可能把它们抹去，复用 ID 则可能使自身调用的归因产生歧义。

## 每条报告路径都排除私有来源内容

即使采集失败，报告也只包含元数据和派生观测。原始提供程序内容或会话正文可能包含提示词、输出和凭证；排障不能成为改变这一披露边界的理由。
