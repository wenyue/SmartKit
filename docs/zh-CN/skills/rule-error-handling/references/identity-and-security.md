# 身份与安全

## 恢复时保持安全边界

区分身份认证缺失或过期、权限被拒绝、身份或完整性证据无效，以及检查执行失败。凭据续期不会授予被禁止的权限；权限检查失败或不可用时，不得允许操作。恢复期间维持正常安全条件，不得跳过完整性验证或扩大授权。

在既定身份和范围内，使用已接受的登录、续期或重新授权路径。续期恢复未来访问，不代表失败操作已经完成。重新发送前应用重放指导；新会话不会消除先前副作用。

延后执行的授权工作结束后，主体、会话、资源和授权发生变化可能使操作授权失效时，验证它们仍允许该操作。使用既有同步或绑定，拒绝过期结果，不将其应用到替换后的身份。

清除凭据或会话元数据前，应用持久化指导。如实返回失败并提供受支持的登录行动已能满足契约时，避免丢失无关数据或强制更换身份。

## 保留有用证据，同时保护私密数据

从日志、公开错误、遥测和反馈中过滤凭据、令牌、密钥和不必要的隐私信息。错误对象、原因链、URL、解码器消息和捕获的载荷本身可能包含秘密；仅过滤新增上下文并不足够。

保留有用的结构事实、适合受众的操作标识、失败类别和可用堆栈。更完整的证据需要既定且获授权的诊断渠道及保留契约。公开反馈所需细节可以少于私密诊断；两者都不应为了说明拒绝而暴露其他主体的数据。
