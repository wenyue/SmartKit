# 编写决策

## 将证据保留与公开识别分开

将诊断证据与调用方可检查的失败标识作为两个独立决定。解包可能暴露实现依赖，而为诊断保留原因并不一定使其成为公共 API。因此，忠实细化豁免要求保留具体原生类别的处理行为，不能把共用异常基类视为兼容性的证明。

## 在宽泛拦截的位置解释理由

维护者注释要求应针对采用统一处置的宽泛拦截。若读者无法看出该处置为何对覆盖的每种失败都安全，宽泛捕获就可能无声地吞掉无关缺陷。常规返回错误传播被明确排除，因为在那里套用同一要求会产生重复注释，却不存在同样的风险。

## 按决策需要展开恢复指导

普通处理、责任归属和反馈政策留在入口。较长的恢复、持久化数据和补救参考文件，仅在作出各自规定的决策时加载。要求每次都读会给常规传播增加负担；把基础政策藏在这些文件中，又会使普通审查遗漏必要内容。
