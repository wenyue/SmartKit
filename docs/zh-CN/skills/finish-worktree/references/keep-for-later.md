# 保留以便稍后继续

按现状保留这棵工作树，让负责人能够继续工作。未完成的实施、未经审查的提交、已暂存与未暂存改动、未跟踪文件，
以及被忽略的本地内容都可以留下。此结果本身不以工作树干净或已经正式审查为前提。

观察足以识别所保留分支与 HEAD、本地工作、已知发布、未完成验证或审查以及恢复资料的状态。记录下一位负责人和具体
恢复工作动作。归属不明的内容应以未解决的不确定性保留；保留不要求消除这种不确定性，也不要求读取每个忽略文件。
保护来源、目标、暂存区、引用和文件。观察期间来源发生变化时，应更新保留记录，不能冻结虚假的准确快照。此前尚未
解决的破坏性操作或发布尝试，仍须交给其恢复负责人；保留不能把该尝试重新标记为成功。

普通保留返回 `history_result: inapplicable`、`outcome_result: proven`、`cleanup_result: complete`、
`status: complete` 和 `classification: non-integrating handoff`。将生命周期项列为有意保留，并标明负责人和
解除保留条件。明确选定的历史准备必须先满足自身契约；保留其结果。此结果只证明工作可留待继续，绝不证明权威交付
或审查完成。
