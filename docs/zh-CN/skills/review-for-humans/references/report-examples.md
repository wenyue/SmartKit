# 报告示例

这些示例展示[面向人类的审查](../SKILL.md)中的必要审查内容与推荐表达方式。需要校准呈现方式时阅读；范围、判断、操作和验证要求由入口文件定义。

## PR 工作区选择 <a id="pr-workspace-decisions"></a>

本示例中的 PR 属于 `team/app`，源分支是同一仓库中的 `feature/export`。只读检查确认 `/work/app` 属于 `team/app`，工作区干净，当前检出 `main`。已有的本地 `feature/export` 分支未在其他位置检出，比已验证的 PR head `b7c9d21` 落后两个提交；目标对象及固定比较证据均可用。此处短提交 ID 仅为显示缩写；实际比较和命令使用已验证的完整 ID。

❓ **Q1** - **是否检出 PR 分支？**：当前工作区的仓库正确，但处于 `main`。是否在审查前将 `/work/app` 切换到已有的 `feature/export` 分支？

- **A**. **检出分支**（推荐）：将这一干净工作区切换到已有的本地 `feature/export` 分支，保持两个分支的顶端提交不变。此选择不更新该分支的版本。
- **B**. **审查固定 PR 快照**：保持检出不变，使用固定快照链接；这些链接不会打开此工作区中可编辑的文件。
- **C**. **取消**：保持检出不变，停止审查。

A 成功后，验证检出结果及分支顶端提交未变，再在展示文件前提出版本选择：

❓ **Q2** - **是否同步到审查版本？**：`/work/app` 现已检出 `feature/export`，但比 `b7c9d21` 落后两个提交。工作区仍然干净，PR 目标未变，可以快进到这一确切提交。

- **A**. **同步**（推荐）：将本地分支快进到 `b7c9d21`，验证最终提交和干净状态，然后使用绑定到 `/work/app` 的实时链接。这不会执行任何推送。
- **B**. **审查固定 PR 快照**：保留较旧的本地版本，使用固定快照链接。
- **C**. **取消**：在此停止，保留已完成的分支检出，不同步。

若其他已注册工作树已检出 PR 分支，在 Q1 中提供选择该已验证路径的选项；不要静默切换工作区。如果 `main` 恰好等于目标提交，Q1 仍需解决分支不匹配的选择；而分支和提交均已验证匹配时，无需 Q2。根据实际未提交状态、本地提交、源 fork 身份及可用安全方案调整选项；这个干净状态下的快进示例不授予 reset、rebase 或丢失工作的权限。

🔧 **M2** - **删除后，仍刷新原来的存储 box**

⏪ **修改前**

```dart
await item.delete();
await item.box?.flush();
```

删除后，`item.box` 变为 null，因此不会执行 flush。

⏩ **修改后**

```dart
final originalBox = item.box;
await item.delete();
await originalBox?.flush();
```

先保留 box 引用，删除记录后就能刷新同一个 box。

⚖️ **合理** 。 通过较小修改，直接修复承诺的删除行为。flush 失败会传递给调用者；flush 不会回滚删除，因此不能把 flush 失败描述成记录已恢复。

🎨 **优雅** 。 在删除位置保留原来的 box 引用，直接处理记录脱离存储 box 的机制，无需额外查找，也不用在其他位置增加状态。
