# 确认自定义 Agent 改动

改动将跨越模型档位、显著增加成本、影响项目的明确选择，或需要用户决定如何处理原生来源冲突或位置调整时，发出询问。已确认当前模型不可用且需要用户选择替代模型时，也要询问。说明受影响的 Agent 和路径。列出当前值与建议值，或当前位置与建议位置，并说明各选项会保留的行为以及需要作决定的成本或运行影响。核实的证据足以支持推荐时，给出建议。等待决定期间，保留冲突的输入。

## 问法

> `<agent>` Agent 目前使用 `<current setting or path>`。<需要决定的原因>
>
> - **A. <第一种可行选项>。** <对该 Agent 的影响>
> - **B. <第二种可行选项>。** <对该 Agent 的影响>
>
> 回复 **A** 或 **B** 就可以。

只提供有支持依据的选项。已确认当前模型不可用且没有已确定的替代模型时，说明需要作出的选择，并把受影响的 Agent 留待处理。
