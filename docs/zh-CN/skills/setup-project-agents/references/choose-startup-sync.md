# 选择启动自动同步

只有在仓库模式下，且用户对当前 checkout 的明确答复和已记录偏好均无法确定选择，或用户要求改变但新值还不明确时才问。匹配的本地成功同步记录会保存开启或关闭的选择。没有该记录时，检查报告中的 `automatic: false` 可能只是默认值。建议默认关闭。这项选择独立于本次的配置应用。开启启动同步后，已有有效绑定和匹配的本地成功同步记录时，可以自动应用已核实的仅仓库改动。仅本地有改动时，询问是否保存或暂缓。两边都改了或方向未明时，需要用户选择。用户之后接受保存时，按维护契约同时授权相应范围的提交和正常推送。

## 问法

> 要让这个 checkout 在启动时检查配置仓库吗？
>
> - **A. 开启启动同步。** 当只有备份发生改动时，会自动应用。上传本地改动或处理两边的差异之前会先询问你。
> - **B. 保持关闭（默认）。** 需要时仍可手动恢复或保存配置。
>
> 回复 **A** 或 **B** 就可以。
