# 选择操作

用户调用 Setup 但未选择操作时才问。先用一句话说明本地配置是否可用，以及是否有已确认的备份。根据证据给出适用选项。

| 检查结果 | 展示的选项 | 建议 |
| --- | --- | --- |
| 本地配置可用，包括新 checkout 中已有的可用配置 | **A. 检查项目初始化状态。** 如果来源已确认，提供 **B. 从配置备份恢复。** 如果来源只是建议或尚未核实，提供 **B. 检查我的备份是否可以恢复。** | 推荐 A。只执行必要迁移，沿用维护选择，并在需要时完成首版 OpenWiki。 |
| 本地配置缺失或不可用，且已确认的来源有此项目的备份 | **A. 恢复现有备份。** **B. 初始化此项目。** | 推荐 A。可以复用现有配置。 |
| 本地配置缺失或不可用，且备份来源未知或尚未确认 | **A. 初始化此项目。** **B. 检查我的备份是否可以恢复。** | 有证据支持初始化时，推荐 A。选择 B 后先确认来源，恢复仍需要现有备份。 |

说明完整 Setup 涵盖项目配置、本地 CodeGraph 和首版 OpenWiki。恢复会将备份应用到当前项目，审查后可能新增、替换或移除文件。如果能从本地快照取得受影响路径，就展示并注明信息来自本地快照。检查仍无法确定来源时，说明尚未核实什么，等用户选择恢复后再确认来源。只推荐现有证据支持的流程。此处只确定本次执行的操作。

## 项目未配置且没有已知备份时的问法

> 你想怎么设置 `<project>`？<项目配置和备份的检查结果>
>
> - **A. 初始化此项目（推荐）。** 建立项目配置、CodeGraph 和首版 OpenWiki。
> - **B. 使用已有备份。** 我会先问备份的位置，再说明恢复会改动哪些文件。
>
> 回复 **A** 或 **B** 就可以。
