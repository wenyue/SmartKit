# 工作树准备技能与配置备份契约

**发布版本：1.2.24。** 现有项目可能仍提供 `worktree-environment-setup`，而 `create-worktree` 现在查找的是 `prepare-worktree-environment`。使用独立配置仓库的项目还可能保留带版本字段的备份清单或同步记录，当前读取器会拒绝这些格式。

在启动冻结会话前，按照 [项目配置维护](../../../maintain-project-config/references/maintenance.md) 检查独立配置仓库模式的状态。源端 `manifest.json` 含有 `version` 字段，或目标端 `.agents/project-config-sync.json` 含有 `version` 字段时，其格式均不受支持。更早的条目若使用单独的源端 `config.json` 和 `.agents/project-config-state.json`，也没有自动恢复路径。保留源文件、目标内容、绑定和同步状态；报告具体不兼容路径，并让依赖这些状态的 setup 保持待完成。请项目所有者在单独授权的恢复方案中决定替代来源、需保留的内容和备份范围。常规 setup 不得转换这些记录或绕过校验。只有通过维护契约建立受支持的源端和本地同步状态后，才能继续。

使用此版本或更高版本执行一次完整 setup，在同一会话中应用选中的更早迁移。将现有项目的 `.agents/skills/worktree-environment-setup/` 目录迁移为 `.agents/skills/prepare-worktree-environment/`，一并携带技能入口、脚本、引用文档、元数据和资源。设置 `name: prepare-worktree-environment`，更新发现元数据、项目自有调用、链接和脚本路径引用，使其指向新名称，同时保留无关元数据和项目特有的环境准备行为。按当前蓝图核对迁移后的技能；没有旧技能时，直接在新路径创建。对于生成内容，交付新输出路径，仅让 setup 退役 `.agents/smartkit.lock.json` 中记录的旧输出。对于未记录的项目自有内容，将必要的移动和删除纳入已接受的编写范围，并保留其内容；缺少授权或目标路径存在冲突时，迁移仍未完成。

完成条件包括：新项目技能可被发现、项目环境准备行为得到保留、不再有仍生效的旧名称技能入口或调用引用、已记录的旧输出已退役、配置收敛且 CodeGraph 就绪状态经过验证。由成功的完整 `finish` 在完成会话清理后记录 `setupVersion`；复制或手工修改的标记不能证明迁移完成。
