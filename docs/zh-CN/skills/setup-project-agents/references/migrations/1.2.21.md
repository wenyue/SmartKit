# 可执行的项目 Skill 与完整界面元数据

**发布版本：1.2.21。** 现有生成 Skill 可能缺少本版本要求的完整界面元数据、可执行的验证指引或脚本化的工作树准备。执行完整 setup 时：

- 按公共写作器的 OpenAI 元数据要求，调整生成 Skill 的 `agents/openai.yaml` 及随附图标素材。
- 更新 `.agents/skills/change-set-verification/SKILL.md` 及必要的支持引用，为每项选定的验证提供有项目依据、可直接使用的调用方式，包括适用的项目强制检查。仅泛泛要求自行寻找检查并不充分。
- 调整 `.agents/skills/prepare-worktree-environment/SKILL.md` 及其脚本，使稳定、可重复的准备通过可靠的仓库自有脚本或最小必要的 Skill 自有脚本执行。对于任何新增或修改的准备脚本，必须在已接受的效果权限下完成蓝图规定的真实目标全生命周期 Acceptance，才能将迁移视为完成。
