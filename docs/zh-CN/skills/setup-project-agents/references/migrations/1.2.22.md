# CodeGraph 就绪状态与 Copilot 项目 MCP 适配器

**发布版本：1.2.22。** 此前已初始化的项目可能尚未满足完整 setup 现在要求的本地 CodeGraph 就绪条件。它们的 Copilot 项目 MCP 适配器也可能仍在使用 VS Code 的配置路径和插值语法。

使用本版本或后续版本执行一次完整 setup，并在同一会话中应用此前选中的所有迁移：

- 启动冻结会话前，通过 setup 的公共准备流程，为目标工作树准备并验证 CodeGraph。保留现有索引数据和独立维护的宿主配置；CodeGraph MCP 声明由 SmartKit 插件拥有。
- 对于声明了 Copilot 项目 MCP 服务器的项目，从规范项目配置重新生成适配器，写入 `.mcp.json` 的 `mcpServers` 下，并采用 Copilot 的环境变量插值语法及已解析的工作区路径。由 setup 仅移除 `.vscode/mcp.json` 中有其所有权记录的字段；保留独立拥有的字段，并在重试前解决报告的所有权或目标冲突。

完成迁移要求本地 CodeGraph 就绪状态已验证、配置已收敛，且完整 setup 的清理已成功。由 `finish` 记录最终的 `setupVersion`；仅凭记录的版本，无法证明其他用户或会话中的运行时已经就绪。
