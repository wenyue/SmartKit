# Skill 界面元数据语言

**发布版本：1.2.20。** 现有项目自有 Skill 必须包含 `agents/openai.yaml`，其中的 `interface.display_name` 使用英文，`interface.short_description` 使用简体中文。专有名称保留原文，用户明确指定的显示标题按原文使用。

执行完整 setup 前，先将已安装的 SmartKit 插件更新到本发布版本，使其迁移读取器能够定位按版本拆分的指引文件。

执行一次完整 setup。检查 `.agents/skills/` 下的每个 Skill，包括项目自行添加的 Skill。通过其权威源文件补齐缺失的界面文件，或调整已有标题和摘要。对于生成的 Skill，将每个 `agents/openai.yaml` 的精确路径纳入已授权的作者写入范围和完整交接，使 setup 将其作为该 Skill 的支持输出一并记录。保留技能标识、调用策略、提示词、其他元数据字段及项目特有行为；已有有效的英文标题和中文摘要保持不变。写入前解决所有权或明确指定标题之间的冲突，然后让成功的 `finish` 记录 `setupVersion`。
