# 确认 OpenWiki 备份

仓库模式下的 OpenWiki 涉及尚未接受的备份文件选择时，使用这一步。说明备份计划已涵盖完整的 `openwiki/` 目录树及任何 `.openwikiignore`。准备纳入 Git 根目录下有改动的 `AGENTS.md` 或已有的 `CLAUDE.md` 时，先展示各个确切路径并审查完整文件，再询问是否纳入。用户接受的是完整文件内容。按维护契约处理权限、计划验证和发布。

## 问法

> OpenWiki 备份会包含 `openwiki/` 和项目的 Wiki 忽略文件（如有）。也要备份整个 `<Git-root entry file>` 吗？
>
> - **A. 一起备份。** 以后恢复这份备份时，可以应用整个文件。
> - **B. 沿用 Wiki 备份范围。** 这份额外文件不纳入。
>
> 回复 **A** 或 **B** 就可以。

有多个符合条件的新增项时，列出它们的确切路径，并接受用户的明确选择。保留已接受的文件范围和准确的计划，用于受保护的保存操作。
