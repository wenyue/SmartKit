# 确认 Setup 操作权限

只有请求的 Setup 范围尚未授权某个必要操作时，才使用这份参考。询问具体操作、受影响的目标和所需的前置条件。对于 CodeGraph，说明当前宿主和项目需要安装、索引或启动什么。对于 OpenWiki，说明实际的 Git 根目录及其中需要写入的内容，尤其是当 Git 根目录与项目目录不同时。沿用对同一操作和目标已有的授权。

## 问法

> 为了继续设置 `<project>`，需要在 `<target>` 中 <执行具体操作>。这会 <直接影响>。
>
> 可以继续这一步吗？

等用户答复后再执行。用户拒绝时，报告待处理的工作，以及可以保留的证据或已完成的工作。
