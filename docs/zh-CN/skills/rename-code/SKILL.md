# 重命名代码

将一个已确定的代码符号或受跟踪仓库路径从 `old` 改为 `new`。沿身份追踪真实用途；拼写相同，本身不使另一个符号属于本次重命名。保留行为，将相邻重构、清理和无关重命名留在范围外。

已接受请求和目标项目治理负责所有读取、写入和命令。本 Skill 覆盖重命名及必要的同一身份引用、生成内容、测试和文档修改。它不授予丢弃、暂存隐藏、重置或覆盖用户工作，直接编辑规范生成输出，提交、推送、发布、发版、部署、创建 worktree、使用网络或进行远程操作的权限。

## 1. 确定身份与兼容性决定

记录一个旧名、一个新名、目标身份、预期范围及每项必要影响的精确权限。定位确立身份的声明或受跟踪路径，区分无关同名对象，以及重载、遮蔽、继承或生成的身份，并排除与其他符号或路径的目标名称冲突。

外部可观察名称是一项契约。对于公开 API，或通过调用者、持久化数据、配置、协议或已发布接口观察到的名称，写入前确定获批的破坏性重命名、分阶段迁移、别名、适配器或不修改决定。不得自行创造兼容策略。

除非获批重命名明确涵盖序列化键、协议字段、数据库列、持久化名称和配置键，否则保持它们不变。代码符号的新拼写本身不授权改变这些契约。

## 2. 追踪身份并确定写入路径

从承载身份的内容及必要集成上下文开始。按能否建立绑定关系选择发现方法：

- 符号引用：语义引用能覆盖相关语言和构建上下文时优先使用；否则结合词法搜索，检查导入、调用点、类型使用、继承、注册、反射和其他承载身份的结构。
- 证据将动态字符串、生成代码、跨语言用途、脚本、测试、文档及构建或配置文件连接到目标时，检查这些内容。
- 路径：结合仓库树、索引、导入、清单、链接和大小写敏感引用。仅文本搜索不能证明完整路径覆盖。

跟进每个已确认用途。当未解决引用、仓库结构、构建元数据、生成所有权或检查失败表明身份可能延伸更远时，扩大调查。仅拼写相同，不足以对无关仓库内容建立清单。

任何写入前，为受影响生成内容确定规范所有者和可用、受支持的生成器。为路径重命名确定安全的版本控制移动，并明确适用的所有者要求检查及可执行路径。

写入前出现以下任一条件时停止：

- 身份、范围、权限，或可观察名称的兼容性决定未解决。
- 目标名称与另一身份冲突。
- 缺少必要生成所有者、受支持生成器、安全移动方式或必要检查路径。
- 已确定的兼容性决定要求不修改。

报告实际阻塞事实或决定及其所有者。已确定不修改意味着重命名不执行，不意味着缺少输入。

## 3. 通过所有者实施重命名

重命名声明或受跟踪路径，以及每个已确认的范围内引用。语义重命名的覆盖可信时使用它；否则明确实施有证据支持的编辑。

遵循各受影响内容的所有权约束：

- 通过规范源和受支持生成器改变生成内容。
- 通过仓库版本控制机制移动受跟踪路径。在大小写不敏感文件系统上，仅改变大小写时，先移动到唯一临时名称，再移到目标。
- 只通过所属接口或模块实施获批兼容措施。
- 只有测试、注释、文档、示例、用户可见文字和身份绑定文件名确实指向被重命名身份时，才更新它们。

安全性或仓库工具要求顺序时，按该顺序操作，例如再生成前更新生成器，或在仅大小写变化的目标移动前建立临时路径。在这些约束内选择普通编辑细节。

## 4. 验证覆盖并修正有依据的遗漏

新拼写不能证明重命名完整。编辑后重复相关的身份感知发现，在受影响内容及必要集成上下文中搜索旧名。只有证据表明覆盖不完整时，才扩大范围。对于路径，重新检查树、索引和路径引用。

将每个仍可能代表目标的出现位置归为：

- 有意保留的契约；
- 无关身份；
- 遗漏的范围内引用；或
- 未解决。

共同证据支持分类时，可合并无关同名对象。逐项列出低信号匹配，不能证明正确性。

针对改变内容和重要重命名风险，运行所有适用的所有者必要检查：按要求包括格式、静态分析、构建、生成输出验证和测试。只有仓库治理或当前证据表明相关时，才扩大检查。兼容措施保留两个名称时，验证每个名称的受支持行为。

当当前证据能将遗漏明确绑定到获批身份，并支持获授权的范围内修正、保留行为与兼容性决定时，纠正遗漏。使用普通工程判断在合理方法间选择，再重复受影响发现和检查。

例如，导入函数的新名在已知调用者处被遮蔽。如果既定范围允许修复该引用，且模块限定与无歧义导入别名都能保留获批绑定和行为，两者都可能合理。选择这些方法，与不确定调用者使用哪个函数，是不同问题。未解决的重载或动态绑定仍需身份依据。

证据不再改善、没有受支持且安全的范围内修正，或继续需要扩大范围、另一个兼容性决定或其他所有者行动时，停止修正。选择方法不能解决缺失身份、权限或重要行为证据。

必要检查不可用或失败时，不能完成。非必要证据不可用，但未留下重要身份或兼容风险时，应缩小完成声明并报告精确未测试表面。

## 5. 报告结果与剩余状态

| 结果 | 必须表达的含义 |
| --- | --- |
| `COMPLETE` | 目标使用获批名称；每个已确认引用使用该名称或获批兼容措施；没有可能属于目标的出现位置未解决；所有适用必要检查通过。记录限制该结论的非关键未测试表面。 |
| `BLOCKED` | 写入前无法确定安全、获授权重命名所需条件，或获批兼容性决定要求不修改。说明实际原因；已确定不修改不是缺少输入。 |
| `FAILED` | 任何写入后，无法安全完成或验证重命名：必要检查失败或不可用、出现位置未解决、修正已耗尽，或需要新增范围或所有者行动。 |

发生写入后，`FAILED` 优先于原本会构成 `BLOCKED` 的条件。保留有用的部分状态和证据，不自行假定回滚权限。

报告映射和身份；兼容性决定；发现方法和覆盖；修改、生成、移动及保留内容；剩余旧名分类和无关同名身份；检查及退出状态；修正；结果；未解决或未测试表面。共同证据支持时，可合并同类已解决出现位置，但必须定位每个未解决、混合或重要例外位置。未完成结果还应包含精确部分状态、停止证据，以及适用时的下一所有者或决定。
