# C++ 边界与所有权

在 C++ 接口和生命周期中明确所有权，尤其关注原生代码与另一种语言、平台或线程相接的地方。

## 围绕所有者设计接口

保留现有 ABI、FFI 和平台边界，同时保持公共接口精简。将行为放在其所有者处。只有相关输入构成稳定概念时，才将它们组织成选项类型。

优先用值语义和 RAII 管理资源生命周期。指针拥有资源时，优先使用智能指针，而不是拥有资源的裸指针。

## 让失败与生命周期契约贯穿边界

在返回契约中表达预期失败；对于所在边界视为异常的失败，使用异常机制。

为共享可变状态指定一个明确的同步所有者，并使用适合需求的最小同步原语。跨原生回调保留清理、取消和线程亲和性要求。

## 验证行为，让项目工具管理机械规范

测试原生所有权、失败处理或 ABI 行为可能回归的边界。由仓库的格式化器、编译器和静态分析配置管理机械性的风格与命名规范。
