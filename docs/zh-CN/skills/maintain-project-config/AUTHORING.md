# 编写决策

## 将共享维护契约放在仅限用户调用的入口之外

Setup 和已启用的启动同步使用受支持的参考文件和命令，不调用这个仅限用户调用的 Skill。绑定、按字节保留的备份、应用选择、同步记录和发布恢复应留在该共享来源中。入口指导显式维护任务，并依赖其必读参考，不重复每项同步条件。

## 保留快照，不据此声称初始化成功

整文件备份有意直接复制原生配置和选定的初始化标记，不重新生成或转换字段。复制的标记或成功恢复，不能证明当前 checkout 执行过初始化或具备本地前提。区分恢复、有意执行的生成和完整初始化，才能使恢复既不改写已接受的字节，也不绕过必要初始化。

## 要求接受实际差异

自动同步是显式的启动偏好，不代表提前接受未来来源与目标的差异。对精确检查状态作出的选择涵盖整次同步，而同步记录只在验证双方一致后推进。仅使用来源指纹或静默三方合并，都会削弱这项已接受的边界。
