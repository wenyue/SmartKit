# 重构代码

重组一个具体目标，消除已经明确的结构压力，同时保持受支持调用方和外部使用者所观察到的行为不变。

## 原则

- **行为就是边界。**内部结构可以改变；受支持调用方可见的行为、不变量和外部契约保持不变。
- **一个压力，一个目标。**范围始终围绕本次已接受的具体目标和结构问题。
- **最小而完整的结构。**将知识收拢到合适位置，只引入由真实边界证明有必要的抽象。推测性的框架、扩展点、兼容层和仅为测试存在的 API 不属于结果。
- **变更各归其主。**遵循目标项目的治理规则，以及每个生成或手写表面的所有者。对一个内部项的权限不代表对另一个也有权限。
- **相称的证明。**为每个受支持边界收集足以区分“保持不变”和“发生回归”的最少证据，并执行所有者要求的每项受影响表面检查。

## 写入前分流

使用获准的仓库读取和非变更性证据，对请求的结果进行分类。相邻 Skill 只能通过其现有公共分发接口使用；不得在此复制其工作流。

- **已转交——重命名。**纯符号或受跟踪路径的重命名属于 `rename-code`，包括公共名称或外部可观察路径。兼容性决策由 `rename-code` 负责。
- **已转交——架构探索。**开放式的架构改进机会探索属于由用户调用的 `improve-codebase-architecture` Skill。这里只确认其探索范围。
- **设计依赖。**只有当既有仓库证据和常规范围内判断无法解决实质性的接口、边界、适配器或测试表面选择时，才使用 `codebase-design`。将其结果与仓库证据核对。若结果要求非重命名的调用方可见行为或外部契约变更，返回**超出范围**；否则继续。
- **超出范围。**任何非重命名的调用方可见行为或外部契约变更都应交由其他工作流处理，包括公共接口、持久化、协议、集成和用户可见行为的变更。

**已转交**、**超出范围**和写入前的**受阻**结果均不写入。重命名交接包含已确认的目标、保持边界、相关证据和所需结果。架构探索交接只包含已确认的范围和结果。超出范围报告包含目标、可观察行为或契约变更的证据，以及所需结果。若分类或返回的设计依赖无法取得的重要材料，返回**受阻**并指出缺少的确切证据。

## 建立边界

写入前，从目标仓库确定：

- 目标、结构压力、预期内部结果和已接受范围；
- 适用的项目规则和所有者，包括每个生成表面的既定所有者；
- 受支持的调用边界，以及这些边界暴露的行为、不变量和外部契约；
- 受影响的实现和调用方路径，以及判断变更所需的测试、配置、历史记录和本地模式；
- 每个受支持边界的保持证据，以及所有者要求的每项受影响表面检查；
- 每项必要读取、命令和写入的权限。

将探索和证明限定在这些义务，以及解释它们所需的集成上下文内。只有当证据暴露出其他实质受影响路径或未解决风险时才扩大范围。无法取得的非关键证据会缩小可支持的结论，并进入交接。若缺少事实、访问权限、操作权限、重要证据或检查路径，导致无法支持安全变更或保持性声明，则不写入并返回**受阻**；明确指出缺口。

## 重组目标

选择能消除压力并收拢知识的最小完整内部结构。只更改必要且经所有者授权的实现表面和内部调用方。只有通过生成表面的既定所有者，并且所需操作已获授权，才能更改生成表面；否则在写入前返回**受阻**。

保留无关状态和用户所有的状态，以及每个受支持边界、行为、不变量和契约。停用某个内部项前，核对所有实质可达的引用。在受支持边界保留行为保持断言；只有在继续保留行为断言时，才更改与结构耦合的测试。

## 证明结果

形成一个完整的内部结果后：

1. 对照既定边界检查最终差异和必要的集成上下文。确认每项编辑都属于获准结果，受影响调用方已迁移，停用的内部项不存在实质可达引用。
2. 运行具有区分力的保持证据，以及所有者要求的每项受影响表面检查。等价声明可复用有效证据；只有存在尚未覆盖的重要风险或独立要求的检查时才补充证明。
3. 只应用由证据唯一确定且属于范围内的修正，然后重跑受影响检查。当证据不再能确定下一步时停止。

## 结果与交接

写入后，若必要检查无法通过或运行、保持证据不再具有区分力、不存在受支持的范围内修正，或同一发现原样重现，则返回**失败**。保留有用状态和证据，不擅自取得回滚权限。写入后的失败优先于同时出现的受阻、已转交或超出范围事实。

只有在结构压力已消除、受支持调用方可见行为和外部契约仍得到保持、被替代的内部项已停用、最终范围符合所有权与权限，并且每项必要检查均通过时，才返回**完成**。

交接内容包括压力和结果；保持的行为、不变量和契约；变更的内部项和调用方；停用的代码；确切检查与退出状态；修正；以及未解决或未测试的表面。非完成结果还需指出停止事实和保留状态。

本 Skill 不授予发布、安装、提交、推送、工作树、翻译、网络访问或远程操作权限。读取、写入、命令和生成表面的权威仍来自目标项目治理。
