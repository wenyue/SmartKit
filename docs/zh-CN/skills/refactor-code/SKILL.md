# 重构代码

在保持受支持调用方和外部使用者可观察结果不变的同时，消除一个具体目标的结构性压力。

## 写入前路由

使用已授权的仓库读取和非变更型证据，对请求的结果进行分类。相邻 Skill 只能通过其当前的公共分发接口使用：

- 纯符号或路径重命名应**Redirected**至 `rename-code`。
- 开放式搜索架构改进机会应**Redirected**至由用户调用的 `improve-codebase-architecture` Skill；只确认搜索范围。
- 对接口、接缝、适配器关系或测试表面的重大选择尚未解决时，只有既有仓库证据和常规的范围内重构判断无法作出决定，才调用 `codebase-design`。将其结果与仓库证据核对：如果结果需要改变调用方可见行为或契约，则通过由用户调用的 `implement` 路由，在不写入的情况下返回**Redirected**；否则在此继续。
- 改变公共接口、持久化、协议、集成或用户可见行为的工作应**Redirected**至由用户调用的 `implement` Skill。

Redirected 结果不得执行任何写入。架构搜索的交接仅携带已确认的搜索范围和所需结果。重命名和实现工作的交接携带已确认的目标、已接受的保留边界、相关证据和所需结果。如果路由或返回的设计依赖无法获得的材料，则在不写入的情况下返回**Blocked**，并指出缺失内容。

## 建立重构契约

执行任何写入前，必须根据目标仓库确定：

- 确切目标、结构性压力、预期内部结果和已接受的范围；
- 适用的项目 Rule 和归属方，包括生成表面的归属；
- 必须保留的受支持调用方接缝，以及可观察行为、不变量和外部契约；
- 判断改动所需的目标、调用方、测试、配置、历史和局部模式；
- 已通过且能够区分保留成功与回归的聚焦型证据，以及归属方要求的每项受影响表面检查；
- 每项必需读取、命令和写入的权限。

如果缺少任何必需事实、访问权限、授权、证据或受支持的检查路由，则在不写入的情况下返回**Blocked**，并指出确切缺口。

## 重构

选择能够消除压力并使实现知识保持局部的最小且内在一致的内部结构。每一层抽象都必须由真实接缝证明其必要性；结果只包含必需结构，不包含推测性框架、扩展点、兼容层或测试专用接口。

只修改必要且归属方已授权的实现表面和内部调用方，同时保留无关状态和用户所有的状态。保持受支持的接缝、行为、不变量和契约不变。淘汰一个内部结构前，核对它的每个真实引用。将保留性断言放在受支持的接缝上；只有仍能保留相应行为断言时，才修改与具体结构耦合的测试。

## 验证并返回

形成一个内在一致的内部结果后：

1. 将确切的最终范围、归属和结构与重构契约对照。证明每项编辑确有必要、调用方均已迁移，并且被淘汰的内部结构不再有真实引用。
2. 运行具有区分力的保留性证据，以及归属方要求的每项受影响表面检查。
3. 只应用由证据唯一确定的范围内修正，然后重新运行受影响的检查。当证据不再能够确定如何取得进展时停止。

写入后，如果必需检查无法通过或运行、保留性证据失去区分能力、不存在受支持的范围内修正，或同一问题原样复现，则返回**Failure**。保留有用的状态和证据，不得臆造回滚权限。写入后的 Failure 优先于同时出现的 Blocked 或 Redirected 事实。

只有结构性压力已消除、调用方可见行为和外部契约仍有证据支持、被取代的内部结构已淘汰、最终范围符合归属边界，并且所有必需检查均通过时，才返回**Complete**。

交接内容包括：结构性压力及处理结果；已保留的行为、不变量和契约；已修改的内部结构和调用方；已淘汰的代码；确切检查及其退出状态；实施的修正；以及未解决或未经测试的表面。非 Complete 结果还必须指出停止事实和已保留的状态。

本 Skill 不授予发布、安装、提交、推送、创建工作树、翻译或远程操作的权限。目标项目的治理仍对读取、写入、命令和生成内容的归属具有最终权威。
