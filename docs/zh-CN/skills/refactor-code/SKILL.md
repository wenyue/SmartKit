# 重构代码

消除一个具体代码目标中已确认的结构问题，同时保留受支持的调用者可见行为、不变量和外部契约。改善知识归属和实现的组织方式。结构问题解释为何要改，受支持契约界定什么必须保留。

## 写入前先确定路径

先通过获授权的仓库读取和不改变状态的证据，判断请求是否为有界重构。相邻 Skills 各自负责其工作，并通过现有公开 Skill 接口调用。

| 请求结果 | 路径 |
| --- | --- |
| 纯符号或受跟踪路径重命名，包括公开名称或外部可观察路径 | 返回 **已转交**，路由到可由模型调用的 `rename-code`。兼容性决定由它负责。携带已确认目标、保留边界、相关证据和必要结果。 |
| 开放式寻找架构改进机会 | 返回 **已转交**，路由到用户调用的 `improve-codebase-architecture`。只确认搜索范围，并将范围和结果要求交给用户调用；不在这里开始搜索。 |
| 非重命名的调用者可见行为或外部契约变化 | 返回 **超出范围**，说明目标、可观察行为或契约变化的证据，以及必要结果。包括公开接口、持久化、协议、集成和用户可见行为变化。 |

具体重构仍可能包含真实设计问题。只有既有仓库证据和普通范围内判断无法解决重要接口、边界、适配器或测试接口选择时，才使用可由模型调用的 `codebase-design`。继续前将其结果与仓库证据核对。若结果要求非重命名的调用者可见行为或外部契约变化，则属于 **超出范围**。

**已转交**、**超出范围** 和写入前的 **受阻** 结果均不执行写入。如果分类或返回的设计依赖不可用的重要材料，返回 **受阻**，指出准确缺失证据。

## 确立保留边界

写入前确定目标、结构问题、预期内部结果和已接受范围。沿受影响实现和调用路径追踪到足以区分可变结构与必须保留的受支持行为、不变量和外部契约。目标测试、配置、历史和本地模式有助建立这些事实时，就使用它们。

### 选择能揭示回归的证据

在每个受支持边界处，根据本次重构可能引入的回归选择保留证据。通过受支持接口观察承诺的结果，而不只是让代码运行一遍。

假设解析器调用者依赖输入顺序保持不变，并要求格式错误记录产生特定错误。只检查解析返回非空列表，无法证明任何一项保证。有用的检查应能区分保留契约与这些回归。

在每个受支持边界收集足以作出该区分的最少证据，并完成所有者要求的全部受影响表面检查。确定适用项目规则、各手写或生成内容的所有者、必要检查路径，以及每项所需读取、命令和写入的权限。对于生成内容，在任何写入前确定通过其所有者执行的获授权操作；直接修改不能替代该路径。

将发现和证明限制在这些义务及解释它们所需的集成上下文内。只有证据揭示另一个实质受影响路径或未解决风险时，才扩大调查。不可用的非关键证据应缩小结论范围，并在交接中说明。若缺失事实、访问权限、授权、重要证据或检查路径，使安全修改或保留声明没有依据，在写入前返回 **受阻** 并说明准确缺口。

## 只调整解决该结构问题所需的内容

选择能消除已接受结构问题并集中知识的最小完整内部结构。由问题来源决定形态：重复知识可能适合放在一起；将同一概念分散的间接层可能值得移除。只有真实边界需要时才引入抽象。预想框架、扩展点、兼容层和仅供测试的 API 不属于结果范围。

如果多个解析分支每次纠正同一转义规则时都必须一起修改，可以用一个内部实现消除知识重复，同时保留行为。可配置的解析框架则需要额外真实变化作为依据。集中已有职责，而不是为假想解析器家族作准备。

仅修改必要且经所有者授权的实现和内部调用者，将范围固定在此目标与结构问题。对一个内部实现的权限，不延伸至另一个。生成内容仅通过其既定所有者及获授权操作改变。全程保护无关和用户所有状态。

淘汰内部实现前，交代所有实质可达引用。在受支持边界保留行为断言；与结构耦合的测试，只有保留行为断言才能调整。测试依赖即将淘汰的辅助方法，意味着应改变到达行为的方式，而不是删除它原本保护的行为。

## 证明结果

形成一个完整内部结果后：

1. 对照既定边界检查最终差异和必要集成上下文。确认每项编辑都属于授权结果，受影响调用者已迁移，被淘汰内部实现不再有实质可达引用。
2. 运行能区分回归的保留证据，以及所有者要求的全部受影响表面检查。相同主张可复用有效证据。只为未覆盖的重要风险或独立要求的检查增加证明；重复同一属性的证据，不能填补另一缺口。
3. 当证据支持已授权的范围内修正，且能保留既定行为、不变量和契约时，修复发现。用普通工程判断在合理方法中选择，优先局部性和简单性，然后重跑受影响检查。

假设重构按组组织并返回记录，但调用者要求输入顺序。保留输入位置或改变遍历方式，都可能恢复该行为。若两者都符合既定契约和授权范围，选择更契合实现且更清楚的方法。如果必要行为或权限未确定，或修改的重要影响未知，停止依赖它的修正：选择方法不能解决这些缺口。

## 报告结果及剩余状态

只有以下条件全部成立，才能返回 **完成**：

- 结构问题已消除。
- 受支持的调用者可见行为、外部契约和不变量仍被保留。
- 被替代内部实现已淘汰，最终范围符合所有权和授权。
- 所有必要检查通过。

写入后，如果必要检查无法通过或运行、保留证据不再能区分回归、现有证据无法支持获授权的范围内修正，或同一发现原样重现，返回 **失败**。失败优先于同时成立的受阻、已转交或超范围事实：交接必须说明已变更状态。保留有用状态和证据，不自行假定回滚权限。

交接结构问题和结果；保留的行为、不变量和契约；修改的内部实现和调用者；淘汰代码；精确检查及退出状态；修正；以及未解决或未测试表面。未完成结果还应指出停止事实和保留状态。
