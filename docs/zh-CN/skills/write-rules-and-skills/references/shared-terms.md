# 共享术语

本文件统一术语含义，供编写和审查角色讨论工件及其版本。

## 工件与 Skill 类型

**Artifact：** 一份 Rule 或 Skill。

**Rule：** 在声明的适用范围内约束相关工作的持续性政策。其要求在核心治理下保留适用性和归属。

**Skill：** 通过原生 Skill 系统提供的、有名称的 Agent 指导单元。它可以通过入口及配套资源提供任务方法、共享知识或政策。

**任务 Skill：** 指导读者执行特定任务或达成某个结果，提供该任务所需的知识和方法；冲突按核心治理规则解决。

**规则导向 Skill（Rule Skill）：** 针对某个领域或条件的政策，遵循核心治理的 `rule-<domain>` 约定，通过原生 Skill 发现机制提供。其适用范围体现了核心治理类型优先级所认可的领域针对性；它仍属于政策，而非任务工作流。

**原则导向 Skill：** 围绕结果、原则、关键约束和完成条件组织的 Skill，将一般方法留给 Agent 判断。

**流程导向 Skill：** 由于顺序或协议会实质性影响结果、正确性、安全、协调、恢复或外部效果，而规定步骤或顺序的 Skill。

**混合型 Skill：** 以原则为主，仅对顺序具有实质性影响的部分规定流程的 Skill。

这些名称描述不同方面。任务 Skill 和规则导向 Skill 区分任务指导与政策；原则导向、流程导向和混合型描述组织方式。规则导向 Skill 可以包含原则和必要流程，同时仍属于政策。这些名称既不规定必需的标题，也不代表质量高低。

## 编写过程中的版本

**Candidate：** 本次任务固定范围内的工件及配套资源。

**Baseline：** 这些资源在写入前的完整状态，在整个任务中保留。

**Fingerprint：** 标识一个完整 Candidate 状态的标识符。不同指纹上的结果描述的是不同版本，即使预期变更很小也是如此。该标识符用于确认版本身份，不证明语义正确。
