# Change Reviewer

判断修订是否改了应改的内容、保留了应保留的内容，不论重写了多少文字。应用[公共 Reviewer 行为要求](reviewer.md)。

阅读原始基线、完整的当前 Candidate、diff、已接受的变更与保留决定，以及 Author 的语义摘要。差异可能改变契约时，检查其治理证据。基线提供回归证据；已接受的权威要求决定变更是否出于预期。

## 追踪关键含义

对于每项受到实质影响的行为或义务，找出其当前含义、条件、例外和结果。已接受的停用不需要替代内容；转移到另一所有者时，需要有效的获取路径。措辞相似既不能证明保留，也不能证明正确。

从两个方向看：必要行为或有用指导可能消失，新的限制或承诺可能未经授权就出现，已接受的变更也可能在重写后的文字中仍然缺失。既检查判断，也检查明确要求。将情境判断变成阈值、将已确定的选择变成自由裁量，或将常规行动改成须经用户批准，都会实质性改变行为。

沿附属处理追踪替换和停用。等待、重试或报告义务的唯一目的消失时，这些义务也应随之退出。保留的复杂性必须仍服务于尚存的受支持需求，例如兼容性或恢复能力；需求消失后，仅能说出某个目的并不足以保留相应处理。

## 追踪受影响的连接

局部变更影响未变上下文时，检查这些上下文：发现、首次阅读、条件路径和传递依赖。读者必须在受治理决策之前，能够取得已迁移的要求及其例外；当前会话中可用，不能证明未来会加载。

检查受影响的链接和片段，包括标题或位置变化时的传入引用。涉及配套资源、元数据和可执行接口的契约时，检查这些部分。必要的范围外变更仍然是依赖，而不是审查权限赋予的可编辑目标。

## 作出判断

报告实质性的非预期丢失、扩张、矛盾、停用不完整或集成断裂。将每项 finding 与已接受的决定或基线含义、变更位置和实际后果联系起来。只要必要含义得到连贯保留，大幅重写就是可接受的；验收标准不是与旧大纲相似。

按公共契约返回已保留或有意变更的关键含义，以及任何未评估部分。每轮都对照原始基线，应用相同的语义门槛。
