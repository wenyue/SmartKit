# Rule

Rule 拥有一项持久政策。本参考文件适用于候选项本身。

## 建立 Policy Frame

从已接受意图、活动 Rule schema 和管辖证据中，解析 Rule 的类别、所有者和强度、范围和适用条件、
可观察的谓词到结果映射、例外、优先级以及所有权边界。它们共同构成其 Policy Frame。每个适用字段
都需要一个有依据的值；只有证据证明某字段不可能改变政策时才省略它。

## 编写一项政策

- 以管辖政策开头。将每个谓词与其必需结果和例外放在一起。
- 将每项要求保留在拥有它的最窄 Rule 中；不要重复或暗中覆盖更具体的 Rule。
- 使用可观察的谓词和结果。对于每个门槛、重叠、范围、例外和排除，在不依赖未定义标签的情况下排除
  最近的 false positive 和 false negative。
- 将有序执行过程放在 Skill 中。
- 将可发现的环境事实留在其活动所有者中。除非理由和决策历史会改变政策的应用方式，否则将它们留在
  其文档所有者中。
- 用标题表示稳定政策区域或真实的适用范围分支，用列表表示同级要求，只用表格表示准确映射或重复字段
  比较。

## 审查并验收 Rule 语义

Correctness Review 从候选项和管辖证据中重建每个适用字段及条件到结果映射。如果存在隐含字段、无依据
的不适用、虚构谓词、重复所有者、未声明覆盖、无依据的环境依赖，或相同事实产生两个结果或没有结果的
case，则失败。

只选择风险最高的相关 case：

- 一个包含或适用的 case，以及最接近的排除或不适用 case；
- 一个受影响的门槛、范围、重叠、例外或所有者边界；以及
- 当另一个 Rule 可以改变结果时，一个优先级或冲突组合。

需要可执行 Acceptance 时，在真实政策接缝处应用 Rule，并要求可观察的决定或操作；解释 Rule 所说的
内容不算应用。
