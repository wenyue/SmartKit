# 生成文件

**强度：** Mandatory

通过规范源文件及其所属生成器维护生成文件。编辑前，依据仓库配置或文档确定这一归属。当源文件、生成器或配置的输入改变了预期输出时，使用仓库声明的工具与设置重新生成受影响的文件。手工修改生成结果不能代替生成过程。

依据获准的变更审查生成结果的差异。无关的输出变化必须先得到妥善处理，才能保留，并保护已有工作。当受影响的源文件与输出通过仓库规定的验证方法确认一致，且所有必需的生成文件都随源文件变更一同交付时，变更才算完成。

如果缺少归属、生成方法、必需工具、验证方式或权限，暂停依赖这些条件的工作，并指出缺失的前提。如果生成或验证失败，报告失败及其造成的文件变化；在一致性得到验证前，工作不能宣告完成。

源文件、工具配置和验证要求由仓库定义。本 Rule 约束获准任务范围内的一致性，不授予额外的写入、安装或网络访问权限。
