# 生成文件

**Strength：**Mandatory

## 修改所属源

通过规范源和所属生成器维护生成文件。编辑前，根据仓库配置或文档确认归属。源、生成器或配置输入改变预期输出时，使用仓库声明的工具和设置重新生成受影响文件。

## 确认一致

对照获授权变更检查生成差异，先解决无关输出变化再保留结果，并保护现有工作。只有源与输出通过仓库验证方法确认一致，且每项源变更都附带全部必需的生成文件，才算完成。

如果归属、生成方法、所需工具、验证或权限缺失，停止依赖它的工作并指出前提。生成或验证失败时，报告失败及产生的文件变更；确认一致后才能完成。

仓库负责源、工具配置和验证要求。在已授权任务内应用本 Rule；它不授予额外写入、安装或网络权限。
