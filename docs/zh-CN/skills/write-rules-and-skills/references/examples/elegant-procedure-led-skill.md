# 替换单个文件

替换一个现有文件，并保留可用的恢复副本，直到结果得到确认。

1. 根据任务和目标环境自身的指令，明确要替换的文件、预期变更、必需检查，以及替换和恢复权限。选择能够保护期间新增编辑的受支持替换方法。无法确定这些前提时，在写入前停止。
2. 单独准备替换内容。保留原文件的可读恢复副本，包括目标环境要求保留的属性，并确认副本与原文件一致。准备和验证候选文件期间，保持原文件不变。
3. 依据预期变更和必需检查验证候选文件。检查失败时，保留原文件：修正候选文件后重新验证，或停止并报告失败的检查。只有候选文件通过全部必需检查，才能继续。
4. 确认原文件仍与恢复副本一致，再使用已确定的方法替换。如果原文件已发生变化，先停止并妥善处理该变化，再尝试替换。
5. 读取目标位置的文件，确认其与已验证的候选文件一致，并通过目标环境要求的检查。如果替换或此次验证失败，检查实际状态；只有既定权限和方法能够保护期间产生的工作时，才恢复原文件。任何恢复操作都必须验证。如果无法安全恢复或无法验证恢复结果，保留恢复副本，停止，并报告已知状态及所需协助。

只有目标位置的文件经验证符合已接受的候选文件，替换才算完成。即使恢复成功，也要报告替换失败。依据目标环境的保留要求和任务权限保留或移除恢复副本；交接时指明保留的副本。
