# 迁移带版本的数据

当步骤顺序十分重要，转换失败可能导致本地数据无法继续使用或受到损坏时，采用此流程。

1. 明确源格式和目标格式、范围内的数据、必需的兼容性、不变量、恢复点，以及写入、恢复和控制数据使用方的权限。任何一项尚不明确，或无法取得独占访问时，都应在修改数据前停止。
2. 准备转换器：转换声明的源版本；输入已经是目标版本时保持不变；拒绝其他所有版本；保留每项不变量；失败时不改变输入。在获准退役旧格式之前，使读取程序同时兼容两种格式。
3. 使用代表性数据的副本运行转换器。比较转换前后的语义内容，测试格式错误的输入，并再次转换结果，以验证重试不会改变数据。修复转换器并重复本步骤，直到所有检查通过。
4. 通过获准的控制方式停止所有读写方，再证明已经取得独占访问。创建不可变备份，记录其校验和与记录数，并确认可以独立读取该备份。任何检查失败时，恢复数据使用方的运行，并在不修改线上数据的情况下停止。
5. 对范围内的线上数据执行一次转换。在常规访问仍被阻断时，立即检查目标版本、记录数和不变量，并用每个受支持的使用方测试读取目标数据。任何检查失败时，保持独占访问并恢复备份。只有恢复后的源数据通过验证，才能恢复数据使用方的运行；否则继续阻断访问并请求恢复方案。报告失败的检查。
6. 所有目标检查通过后，恢复数据使用方的运行。
7. 只有保留期限和兼容性要求允许时，才能退役备份或旧格式读取程序。否则，应在交接时记录其负责人和到期条件。

范围内的所有数据都通过目标格式验证、受支持的使用方都能读取、不存在部分转换，并且每项继续保留的恢复或兼容措施都有明确负责人和移除条件时，迁移才算完成。
