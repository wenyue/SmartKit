# 替换一个文件

替换一个现有文件，在结果确认前保留可用的恢复副本。

## 1. 准备并验证

**确立契约。**从任务和目标指令中确定文件、预期变更、必需检查，以及替换和恢复权限。选择能保护期间新增编辑的受支持替换方法。任何前提缺失时，在写入前停止。

**单独准备。**制作替换候选内容和可读的恢复副本，包含必需属性。确认副本与原件一致；准备和验证期间保持原件不变。

**验证候选内容。**确认预期变更并运行每项必需检查。失败时保留原件，在修正候选内容后重新验证，或带着失败检查停止。只有验证通过后才能继续。

## 2. 替换并确认

**检查期间新增的编辑。**确认原件仍与恢复副本一致，再按已确立的方法替换。若原件有变，先停止并解决该变更。

**验证目标文件。**读取目标，确认它与已验证的候选内容一致，并运行必需检查。替换或验证失败时，检查状态。只有已确立的权限和方法能够保护期间新增的工作时，才恢复原件，然后验证恢复结果。安全恢复或验证不可用时，保留恢复副本并报告已知状态与所需协助。

只有目标文件经验证与已接受的候选内容一致，才算完成。即使恢复成功，也要报告替换失败。按照目标的保留要求和任务权限处理恢复副本，并在交接中指出任何保留副本。
