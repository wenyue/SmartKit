# 决策备忘录

撰写一份简洁的备忘录，使负责决策的人无需重新梳理调查过程，就能理解当前选择、检验其依据并采取行动。

## 原则

- **决策优先。**先说明建议及其状态，再提供支持细节。
- **比较关键差异。**根据可能改变选择的标准比较可行方案；省略不会影响选择的差异。
- **置信依据可追溯。**区分已经确认的事实、合理推断和尚未解决的假设，并提供可供读者核查的证据链接。
- **重视后果，不只倡导方案。**成本、风险、可逆性和实际执行影响，应与收益一样清楚。
- **详略得当。**把篇幅用于有争议或不可逆的决策部分，压缩已经确定的背景。

只处理当前提出的决策。查清能够核实的事实，但不得编造缺失的业务标准、擅自指定决策负责人或实施建议。如果缺少会实质影响选择的标准或决策负责人，应准确请求该项输入，并暂停撰写备忘录。

备忘录在满足以下条件时完成：明确决策及其负责人；推荐一个方案；记录重要的备选方案和判断标准；说明证据与取舍；揭示会产生实质影响的假设和风险；并指出仍需完成的审批或后续行动。
