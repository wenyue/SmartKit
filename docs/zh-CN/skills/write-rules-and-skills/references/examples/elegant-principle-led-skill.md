# 决策备忘录

编写一份让负有决策责任的人能够理解选择、质疑依据并采取行动的备忘录，而无须重新梳理整个调查。让决策成为焦点；背景只有在会改变决策方式时才值得占用篇幅。

## 找出什么可能改变选择

从决策本身、负责人及其关心的结果出发。利用提供的上下文和可以查明的事实，识别可行选项和重要差异。如果重要目标、标准或决策者仍不明确，先请求补充那项具体信息，再推荐依赖它的选项。保留不依赖该信息、仍有用的比较。

在相同基础上比较各选项。更便宜的服务可能把工作转移到用户团队；如果这部分工作可能推翻表面上的节省，就把它纳入比较。不满足硬性要求的选项，不会因为其他指标占优就变得有竞争力。说明排除它的原因，然后将篇幅用于仍然可选的方案。

寻找决策的支点：建议取决于哪项事实或判断？如果某项服务仅在预期流量下更便宜，就展示合理范围内的流量变化如何影响选择。如果切换回来代价高昂，这种不确定性就比容易撤销的细节更值得关注。根据问题选用计算、小型比较表或段落；评分矩阵只有在尺度和权重有合理依据时才有用。

## 让置信程度有据可查

让证据、推断和假设能够被区分。供应商注明日期的报价是证据。根据报价和预测用量计算的年度节省是推断。供应商尚未承诺的续约费率是假设。为重要主张链接可查阅的来源，并展示比较背后的假设，而不是让每句话都带着相同的确定语气。

在任务范围内查明能够确定的事实。仍有不确定性时，解释它会改变建议、使建议附带条件，还是让决策无法作出。不要为了完成备忘录，就把缺乏依据的估计变成事实。

## 围绕决策展开表达

先给出建议及其状态。解释它为什么更优，也包括选择最接近的另一方案的最有力理由。对重要成本、风险、可逆性和实际运作影响的关注，应与收益相当。展开有争议的点，压缩已经明确的背景。

当读者能够识别决策及负责人、理解重要备选方案和取舍、查阅建议依据，并看出需要什么批准或后续行动时，备忘录就已就绪。选择能支持这种阅读的长度和结构。产出备忘录，并不等于选定负责人、批准建议或授权实施。
