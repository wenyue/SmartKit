# 决策备忘录

生成一份简洁备忘录，让负责决策的人无需重建调查过程，就能理解选择、质疑依据并采取行动。

## 原则

- **决策优先。**先说明建议及其状态，再提供支撑细节。
- **实质比较。**按可能改变选择的标准比较可行方案；压缩不影响选择的差异。
- **信心可追溯。**区分证据、推断和未解决假设，并链接可检查的来源。报价是证据；预计节省额是推断；未知的续约费率是假设。
- **后果。**像呈现收益一样，清楚呈现成本、风险、可逆性和运营影响。
- **适当篇幅。**展开有争议或不可逆的部分，压缩已确定背景。

## 范围与完成

留在当前决策范围内，并研究可查明的事实。缺少实质性标准或决策负责人时，请求准确输入并暂停备忘录。负责人的选定和建议的实施仍由各自权威负责。

完成的备忘录应明确：

- 决策、负责人、建议选项和重要备选方案；
- 标准、证据、权衡、有实质影响的假设及风险；
- 所需批准或后续行动。
