# 文档目标变更

## 确定受影响引用

移动、重命名或删除文档前，在任务与项目确定的文档范围内检查传入链接。按项目解析规则涵盖片段和等价路径形式。审查中判断完成前也要检查同样的影响。必需文档或引用证据不可用时，报告缺口并暂停依赖它的变更或结论。

## 处理目标

| 变更 | 必需处理 |
| --- | --- |
| 移动或重命名 | 将受影响链接更新到目标位置，并确认片段仍指向预期内容。 |
| 删除 | 重定向到已检查且支持链接含义的替代内容；否则在获授权范围内移除或修订依赖该目标的引用。 |

必要修复超出范围时，停止依赖它的目标变更，并指出所需权限。按请求进行审查时，记录未解决的修复，不进行编辑。

## 验证完成

变更后检查受影响的传入链接。文档被移动时，还要检查相对路径可能改变解析结果的内部链接。确定范围内的每条受影响引用都必须可解析；报告结果时说明该范围。
