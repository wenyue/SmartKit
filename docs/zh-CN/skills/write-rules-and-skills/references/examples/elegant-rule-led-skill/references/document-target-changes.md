# 目标文档变更

**适用范围与强度：**继承自[文档链接](../SKILL.md)。

在目标文档移动、重命名或删除前，检查任务和项目所确定的文档范围内指向该文档的链接。包括指向其片段的链接，并依据项目的解析规则查找等价路径写法。审查时，也应先检查相同的影响范围，再判断目标变更是否完成。如果无法获取所需文档或引用证据，报告缺口，暂停依赖它们的变更或结论。

对于移动或重命名，将受影响的链接更新为新目标，并确认其片段仍指向预期内容。对于删除，只有经过检查的替代内容能够支持原引用含义时，才重定向链接；否则，在获准范围内移除或改写依赖它的引用。如果必要修复超出该范围，停止依赖此修复的目标变更，并指出所需权限。对于用户要求的审查，记录尚未解决的修复，不作编辑。

变更后验证受影响的入站链接，并检查被移动文档内部的链接，因为它们的相对路径可能已产生不同的解析结果。既定范围内的每个受影响引用都得到妥善处理，工作才算完成；报告该范围，避免让结果暗示覆盖了范围之外的内容。
