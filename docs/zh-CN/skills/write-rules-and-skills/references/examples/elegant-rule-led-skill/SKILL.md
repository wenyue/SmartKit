# 文档链接

强度：`Default`

适用范围：当前工作影响的文档链接，以及用户要求的文档链接评估。

## 确保目标可验证

依据目标项目的路径和发布规则，从源文档出发解析新增或修改的链接。检查目标内容及链接中的片段标识，确认链接指向预期内容。使用准确描述该内容的链接文字；页面可以访问，并不足以证明引用正确。

将修正限制在获准的文档和预期含义内。通过项目支持的检查和目标内容证据验证最终链接。当每个受影响的链接都指向预期内容，且必需检查通过时，链接工作才算完成。如果无法获取目标内容、解析规则或必需检查，报告证据缺口，暂停依赖这些证据的编辑或结论，不得将未经验证的链接视为有效。

## 目标文档变更

链接指向的文档发生移动、重命名或删除时，在决定如何处理相关链接或作出审查判断前，阅读[目标文档变更](references/document-target-changes.md)。如果该资源缺失或无法读取，停止依赖它的决策，并报告缺失资源。

## 用户要求的评估

覆盖请求范围内的链接，在现有工作报告中说明有依据的缺陷、已验证的范围和证据缺口。评估不授权编辑；加载此政策也不增加修改文档或访问目标的权限。
