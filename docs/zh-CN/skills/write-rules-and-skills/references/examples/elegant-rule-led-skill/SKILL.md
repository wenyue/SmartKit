# 文档链接

Strength: `Default`

## 新增或变更的链接

按照项目的路径和发布规则，从源文档解析每个链接。检查目标和片段，再选择能说明目标内容的链接文字。标为“安装”的链接必须到达预期安装指导，仅能访问一个有效 URL 并不足够。

修正应限于获授权文档和预期含义。每个受影响链接都到达预期内容，且项目必需检查通过后，链接工作才算完成。目标证据、解析规则或检查不可用时，报告缺口并暂停依赖它的编辑或结论。

## 目标文档变更

在决定如何处理指向被移动、重命名或删除文档的链接前，或在审查中判断这类变更前，阅读[文档目标变更](references/document-target-changes.md)。资源缺失或不可读时，报告问题并停止依赖它的决策。

## 所请求的评估

在现有工作报告中覆盖所请求的链接：有依据的缺陷、已验证覆盖和证据缺口。评估不授权编辑；在另行确立的文档变更或目标访问权限内应用本政策。
