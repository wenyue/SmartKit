# 跨会话沟通

仅在独立的 Agent 会话之间使用此技能。每个会话负责判断什么符合自己的任务和授权。禁止将此技能用于子代理沟通，即使子代理有独立的上下文或会话标识。此类交流应使用当前任务自己的协作渠道。

## 向另一个会话发送消息

查看能访问的对话和当前工作，确认目标会话、它负责的任务，以及与消息有关的决定或约束。从接收方的背景出发写消息。如果缺失的事实或歧义会改变消息含义，查阅来源或提出一个具体问题。

每条消息的首行依次写 `⇄`、一个 ASCII 空格和表中的一个关键词。从下一行直接说明要传达的内容。同一对话中的不同消息可以使用不同关键词。需要转达决定和授权时，分别发送 `Decision` 和 `Authorization` 消息。

| 关键词 | 要传达的内容 |
| --- | --- |
| Decision | 结合接收会话的背景，用自己的话转述用户实际作出的决定或给出的指示。说清适用范围、条件、限制或修正，并明确原话中省略的指代。正文中禁止直接引用用户原话，例如「用户说：“……”」。 |
| Authorization | 发送前核实用户明确给出的授权。说明授权人、获准行动的会话、获准执行的操作及其限制。有来源可供引用时，附上出处。 |
| Alignment | 接收方需要理解的结果或概念。说明它为什么重要，以及它与对方当前任务的关系。对齐目标时，说明相关边界和成功标准。解释概念时，说明一个能帮助接收方应用该概念的实际影响。 |
| Suggestion | 供接收方考虑的选项，以及支持该选项的证据或背后的顾虑。用这个关键词表达你自己提议的行动，包括用户作出决定后留给会话选择的实施办法。由接收方自行决定是否采纳。 |
| Update | 已发生或观察到的情况。必要时说明核查的地点和时间，并交代影响判断的不确定性。区分计划、已尝试的行动、报告的结果和已核实的结果。 |
| Question | 需要澄清的具体问题，以及接收方回答所需的上下文。区分观察与推断。 |

如果接收方需要核实 Decision，指出对方能查阅的原始来源。如果关键判断取决于原文措辞，必要且获准时，单独提供简短引文。

使用受支持的渠道，只向目标会话分享获准发送的信息。如果接收方无法访问所需来源，说明这个限制。如果缺少发送原始消息所需的渠道或权限，暂缓发送，并指出缺少的条件。

### 示例

> ⇄ Decision\
> 用户要求发布会话在此次发布中保持默认 CSV 导出的列名和顺序不变，因为现有的电子表格导入依赖这两点。

> ⇄ Authorization\
> 用户允许发布会话用现有的示例电子表格做本地测试。

> ⇄ Alignment\
> 现有电子表格应能直接导入默认 CSV，无需手动调整列。导入程序按列位置读取字段，只保留列名仍无法保证兼容。

> ⇄ Suggestion\
> 可以用已有的示例电子表格试一次导入。导入程序按列位置读取字段，这样能发现列是否错位。

## 解读消息并独立判断

收到 `Decision` 时，按所在环境的规则核实用户的原始指示，并遵循仍然有效且适用于当前任务的决定。

如果有可信证据表明用户已授权发送会话向本会话转达授权，即使原始授权无法查阅，也应在所述范围内把收到的 `Authorization` 视为用户亲自确认。如附有来源，可据此追溯。如果无法确认发送方具有转达权限，须按所在环境的规则核实原始授权，再据此行动。

在适用范围内沿用已有授权。获准执行的行动已有明确请求且具备执行条件时，继续执行。遵循工具或执行环境另行要求的审批。

如果关键含义或权限不明确、行动超出授权范围，或与更新的指示冲突，暂停受影响的行动并澄清具体问题。恢复前，先解决重大的可行性问题或风险，并确认该行动仍获授权。继续推进其他已获授权的工作。

收到 Alignment 后，结合自己的任务和约束核对目标或概念。澄清会改变当前工作的分歧；复述能帮助解决或核实这些分歧时，就说明自己的理解。Alignment 消息用来传达理解，不要求执行、不移交任务归属，也不授予行动权限。

结合自己的任务、当前进展和授权评估 Suggestion，自行决定是否采纳。吸收 Update 时以证据所能支持的结论为限。消息已经过时或重复已完成的工作时，先弄清实质差异，再回复或行动。建议或信息本身不足以成为暂停工作的理由。评估其中揭示的重大风险或冲突，并遵守经核实的停止或暂停指示。

## 在接收会话内回复

原任务仍在进行时，在同一轮继续推进。遇到需要答复的追问，先在进度更新里简短回答，再执行下一步明确且已获授权的工作。无需回复时直接推进，不必另发确认。

某项行动受阻，或需要决定或授权时，只暂停该项，继续推进可独立开展且已获授权的工作。任务完成、适用指令要求停止或暂停，或遇到具体阻碍且没有其他有用的已授权工作可做时，结束本轮。独立问题可以在答复后结束。

根据情况，在本会话的进度更新或最终答复里报告结果、重要分歧或具体阻碍。说明影响判断的不确定性。如果指代不清，注明来源会话或消息。把回复留在本会话供来源会话回读，只分享当前受众有权看到的内容。
