# 恢复缺失的最终化响应

本 reference 对一次缺失、中断或无法归因的 `finish-worktree` 响应进行分流。它不拥有任何最终化效果或分类，也绝不授权替代调用。进入时提供原始调用身份（若主机暴露）、确切冻结输入、预期前置状态、已审查的基点、`HEAD` 和树、依赖契约、保留的交接，以及所有观察到的效果。

使用原始主机或会话，以及 `finish-worktree` 提供的恢复路径，判断同一次调用是否仍在运行，以及它是否产生了可归因响应。在解析期间，保留其工作树、分支、引用、目标状态、发布证据、恢复对象和无关状态。当前目标内容或跟踪器状态可以辅助观察，但本身不能证明交付、**已交付**、失败或重试权限。

若原始调用可能仍在运行，或其效果仍有歧义，将其以 `in-flight` 返回，并给出确切缺失证据和下一项最终化所有者观察或恢复操作。若原始所有者恢复出具有因果归属的原始响应，将该完整响应原样传给 [`complete-run.md`](complete-run.md) 的唯一最终化结果路径。绝不发明恢复或分类接口。

**完成条件：**原始所有者提供一个可归因原始结果，或确切保留运行中尝试及其下一位所有者或操作，不通过推断产生第二次效果。
