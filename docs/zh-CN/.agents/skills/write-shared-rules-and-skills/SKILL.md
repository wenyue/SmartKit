# 编写共享 Rule 与 Skill

先判定一个跨项目 SmartKit Rule 或 Skill 是否具备可移植性，再通过公共
[`write-rules-and-skills`](../../../skills/write-rules-and-skills/SKILL.md) 工作流编写它。本 Skill
仅负责可移植性方面的增量要求。判定请求是否符合条件时，必须完整阅读
[`references/portability.md`](references/portability.md)。

## 判定共享输入是否符合条件并将其封闭

评估可移植性之前，先解析制品所有者。对于项目本地请求、Setup 请求、拆分请求、环境所有请求、
非共享请求或含糊请求，遵循参考资料给出的终止路由。只有一个跨项目 SmartKit Rule 或 Skill
具备有依据支持的所有权和出处时，才继续执行。

构建一个封闭的任务/规范输入，其中包含已接受的可移植含义、Candidate 表面、经资格判定的证据、
完整的依赖路由、代表性接缝与目标、公共工作流授权模型下已接受的权限与影响、验证职责及完成条件。
从代表性目标推导出的事实只有在通过资格判定后才算作证据。目标资源只有在另行接受权限后才可读取或
用于公共 Acceptance，且绝不获得 Candidate 变更权限。若仍有任何实质性选择未确定，则在调用公共
工作流之前返回公共 `ALIGNMENT_REQUIRED` 载荷。

**完成条件：**每项可移植性义务都有一个已接受的答案、证据资格、通过条件和获授权路由。

## 原样调用公共工作流

在公共工作流入口，将封闭的共享输入原样作为普通的已接受任务/规范输入提供。公共工作流独占其
Candidate 模型、冻结与指纹、运行时与角色、证据选择、证明阶段、修正、出口和最终化。本 Skill
不增加任何此类机制，并原样保留公共工作流的每个终止结果。

对于本 Skill 的自托管变更，Author 开始前冻结的公共合同和私有合同在整次运行中始终具有权威；
编辑后的字节只在后续调用中生效。

**完成条件：**公共工作流返回其交接或终止结果。

## 项目可移植成功

应用参考资料中的最终指纹闭合测试，且不重新解释任何公共裁决。可移植成功既要求公共工作流成功，
也要求每项可移植性义务针对公共工作流的最终 Candidate 指纹保持当前闭合。保留公共交接，并附加
闭合说明；若闭合不完整，则附上未覆盖的义务和缺失证据。

资格判定和覆盖证据仅保留在临时状态。本 Skill 不授予发布、安装、commit、push、release 或任何
其他下游影响的权限。

**完成条件：**公共结果得到保留，并且交接时每项可移植性义务均得到说明。
