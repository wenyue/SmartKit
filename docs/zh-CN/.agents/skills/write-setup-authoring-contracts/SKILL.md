# 编写 Setup Authoring Contract

在 `setup-assets/blueprints/**` 下编写或修订最小而完整的一组仅用于判断的 Setup Authoring Contracts。每份契约都为未来一个 Rule 或 Skill 提供已接受的基础。Candidate 效果仅限这些契约文件；另行产生的结果是下文定义的交接报告。设计契约前，读取并应用当前检出中具有权威性的 `writing-for-agents` Skill。

## 原则

- **一份契约，一个目标。**一份契约负责恰好一个未来 Rule 或 Skill 目标的含义和证据。纳入已接受项目意图所要求的每份契约，不添加推测性目标。
- **合格证据。**从已接受的用户决策，以及当前具有权威性的 Issues、Specs、ADRs、治理契约、目标所有者证据和可观察目标行为中推导含义。根据语义所有者和来源评定每项资料。既有契约是完整性和回归证据，而不是完整性证明或设计权威。
- **描述性契约。**规定未来目标必须表达什么含义、允许什么、验证什么、返回什么，以及遇到什么情况应停止。将设置探索、排序、工具选择、重试、写入和生成机制留给其运行时所有者。过程导向目标必须表达其受支持流程，但它的 Setup Authoring Contract 仍然是描述性的。
- **精确权限。**只有确切路径和操作分别获得授权时，才可创建、替换、删除或移动契约；否则在写入前停止。非规范性上下文、仓库可见性、可发现性、工具可用性、目录元数据或写入访问权限，都不授予含义或操作权限。保留每个无关路径和独立所有表面。
- **效果分离。**只有 `setup-project-agents` 负责下游生成和设置执行。本 Skill 不生成未来目标或共享 SmartKit 工件，不实现设置编排，也不执行翻译、安装、发布、提交或推送。

## 每份契约确立的内容

确定最小完整契约集合中的确切路径。对于每份契约，使以下事实能够从已接受证据中重建：

- 未来目标的目标、执行者、触发条件、确切路径、Rule 或 Skill 语义类型和所有者；
- 设置必须向未来 Author 提供的目标仓库证据及其来源；
- 每项会改变行为的义务，并将其分类为保留、变更、新增、停用或非目标；
- 未来 Author 的确切 Candidate 和写入路径；分别获准的创建、替换、删除和移动操作；其他权限及允许的外部效果；以及必要验证；
- 未来目标和未来编写运行支持的每一种结果，各自附带可观察的判别条件；
- 每项缺失权限、不受支持的事实或实质性歧义；遇到这些情况，未来 Author 必须停止，而不是自行发明目标事实、所有者、策略、权限或操作。

优先使用提供的任务、Candidate 和证据。只有适用指令或具体需要时，才在确切授权范围内探索额外材料。写入前，确保每项义务都有一个已接受的处置结果或明确停止条件，而且每项未来操作都符合其授权。

将每份契约写成连贯的规格，而不是实现步骤。将每个触发条件与其结果、判别条件和退出放在一起，并让每项承诺归其语义所有者。当每条指令都会改变一种受支持的生成或停止结果，而且每一种这类结果都无需自行发明项目事实便能得出时，这组契约才是最小的。

## 本 Skill 的停止结果

对于当前契约编写运行，若尚不能安全编写契约集合，使用以下例外结果：

- 必要证据或验证在授权范围内无法访问时，使用 `ACCESS_REQUIRED`。
- 已有访问权限，但无法从合格证据中发现必要事实时，使用 `CONTEXT_REQUIRED`。
- 实质性选择超出已接受权限时，使用 `HUMAN_DECISION_REQUIRED`。

对于缺少访问权限或上下文，报告确切需求、获准探索为何无法满足它、可以解决问题的所有者或条件、其后果，以及新运行所需的权限和可观察条件。对于决策，指出其所有者、当前可选项、证据和后果。只有缺失输入和重试权限均已确立后，才能在一次新运行中恢复。

## 验证与交接

运行每项适用、由所有者支持的确定性非修复检查。只有合格的所有者证据证明没有此类检查适用时，才记录 `NOT_REQUIRED`。然后以静态方式证明完整集合：

- 始终仅用于判断，且处于蓝图所有权范围内；
- 核对了每项会改变行为的义务和未来 Author 权限；
- 将每种受支持输入映射到恰好一种可观察的生成或停止结果；
- 无需任何不受支持的项目事实即可到达每一种结果。

检查失败、所有权冲突或实质性歧义未解决时，不能完成。只有每项检查通过或被记为 `NOT_REQUIRED`，并且静态证明闭合时，才算完成。

返回确切的契约路径和所有者、受支持结果、检查及结果、保留约束，以及不确定或未测试表面。只将契约作为 ready 输入交接给 `setup-project-agents`；不要调用它或产生下游效果。
