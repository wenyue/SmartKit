# 编写 Setup Authoring Contract

在 `setup-assets/blueprints/` 下编写最小而完整的一组 Setup Authoring Contract。
本 Skill 仅负责这些契约；生成的目标和共享 SmartKit 工件仍由各自的所有者负责。全程应用
`writing-for-agents`。

## 1. 确立契约依据

依据已接受的用户决定、Issue、Spec、ADR、管辖契约、setup catalog、存在时的当前蓝图，
以及可观察的目标实现证据来确立契约。`CONTEXT.md` 和 `CONTEXT-MAP.md` 不提供语义权威、
证据、验证输入、依赖或持久术语。setup 控制器和未来 Author 可在授权访问范围内直接检查目标
仓库。除非已接受的意图要求变更，否则保留有依据的现有蓝图语义。除非已接受的意图明确变更或
废止，否则保留有依据的现有目标语义。应停止，而不是虚构目标事实、所有者、政策或操作。

对于 `setup-assets/blueprints/` 下每一个确切的预期契约路径，依据管辖证据确立一个包含以下
内容的 Setup Contract Frame：

- 准确的未来目标路径、Rule 或 Skill 语义类型和目标所有者；
- setup 必须检查并提供给未来 Author 的目标仓库证据；
- 每项会改变行为的目标义务，包括保留的义务、变更的义务和非目标；
- 未来 Author 可以写入的路径、其其他权限，以及 setup 必须验证的表面；
- 区分有依据的目标结果的条件；以及
- 导致生成停止的准确实质性歧义、缺失权威或无依据事实。

如果仍存在实质性的行为、所有权、权限、验证或退出歧义，则在写入前返回
`ALIGNMENT_REQUIRED`。列出每项未解决的选择、可用证据、决策所有者和实质性后果。
不得调用 `grilling`。

**完成标准：**证据足以为每个契约确定无歧义的范围，并且每项会改变行为的义务都有已接受的值或
明确的停止条件。

## 2. 编写契约

只写入 `setup-assets/blueprints/` 下确切的预期契约路径。对于每个契约，
将已确立的 Setup Contract Frame 表述为 setup 必须确立的含义和证据。把相关分支放在各自的
触发条件旁，并为每种结果提供可观察的判别条件。

契约应保持仅用于判断且最精简。描述含义和证据，而不是 setup 如何搜索、安排工作顺序、调用工具、
写入文件、重试或实现生成。实现事实仍由各自的所有者负责，并且不得生成未来的 Rule 或 Skill。
不得把未来 Rule 或 Skill 的过程复制到契约中：对于以过程为主导的目标，契约仍保持描述性，
同时要求生成的目标表达有依据的过程。

**完成标准：**每个有依据的生成或停止结果都能从其契约中得出，且不含虚构的项目事实；删除任何一条
指令都会改变一个有依据的结果。

## 3. 检查与审查

运行现有且适用的确定性非修复检查。如果不存在此类检查，则记录 `NOT_REQUIRED`。修正在范围内的失败，
并重新运行受影响的检查。

随后，对完整契约集合进行静态审查，检查：

- **仅用于判断的形式：**契约规定所需的含义和决定，但不规定 setup 的生成过程；
- **最精简性：**每条指令都会改变一个有依据的生成或停止结果；
- **语义完整性：**每项会改变行为的义务都已确立，或会导致明确停止；以及
- **代表性走查：**对于每个契约，一个有依据的目标输入在不虚构项目事实的情况下，恰好到达一个生成
  或停止结果。

如果适用的检查问题或审查问题无法在确切的预期契约路径内修正，则立即以阻塞结果停止。报告相应的检查或
标准、证据、阻塞因素或所有者，以及尝试过的修正。如果该问题暴露出新的实质性歧义，则改为返回
`ALIGNMENT_REQUIRED`，并附上第 1 步的报告。这两种结果都不算完成第 3 步，也不能进入交接。

修复每个有依据的审查问题，然后重新进行完整审查。如果同一个确定性检查失败或静态审查问题经过两次
修正尝试后仍然存在，并且没有新证据或有依据的解决方案，则以 `NO_PROGRESS` 停止，并报告失败的检查
或标准以及尝试过的修正。

**完成标准：**所有适用的检查均通过或记录为 `NOT_REQUIRED`，并且当前完整契约集合通过全部四项审查标准。

## 4. 完成

第 3 步完成后，逐个契约报告其路径和所有者、适用的检查及结果、四项标准的审查结果，以及任何非阻塞的
未解决或未测试表面。报告这些契约已准备好交给下游所有者 `setup-project-agents`；不得调用该 Skill，
也不得生成下游目标。commit、push 和发布仍不属于本 Skill 的范围。
