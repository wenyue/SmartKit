# Setup Authoring Contract

## Setup Contract Frame

根据管辖证据建立：

- 准确的未来目标路径、Rule 或 Skill 语义类型和目标所有者；
- setup 必须检查并提供给未来 Author 的目标仓库证据；
- 每项可以改变行为的目标义务，包括保留要求和非目标；
- 未来 Author 可以写入的路径，以及 setup 必须验证的表面；
- 区分受支持目标结果的条件；以及
- 导致生成停止的准确实质性歧义、缺失权威或无依据事实。

## 保持契约仅用于判断

描述生成必须确立的含义和证据。不要规定 setup 如何搜索、安排工作顺序、调用工具、写入文件、
重试或实现生成。不要把未来 Rule 或 Skill 的过程复制到契约中。面向过程型目标的契约仍是描述性的：
它要求生成的目标表达有依据的过程，但不把该过程变成 setup 算法。

让 setup Controller 和未来 Author 在授权访问范围内直接检查目标仓库。保留有依据的现有目标语义，
除非已接受意图明确变更或废止它们。应停止，而不是虚构目标事实、所有者、政策或操作。
