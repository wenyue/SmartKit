# 项目设置编写契约

## 项目设置契约框架

根据证据建立：

- 确切的未来目标路径、Rule 或 Skill 语义类型，以及目标责任方；
- Setup 控制器必须检查并提供给作者的目标仓库证据；
- 值可能改变行为的每项目标义务，包括保留项和非目标；
- 作者可以写入的路径及其必须验证的界面；
- 选择一个目标结果的条件；以及
- 会停止生成的确切实质歧义、缺失权限或无依据事实。

描述必需的目标含义，但不强加大纲或无依据的编写顺序。让 Setup 控制器发现目标仓库中的项目事实，并在
上下文包中纳入无工具作者所需的每项事实。保留有依据的现有目标语义，除非已接受意图明确
变更或退役这些语义。
