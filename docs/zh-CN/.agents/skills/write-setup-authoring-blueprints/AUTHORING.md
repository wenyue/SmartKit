# 编写决策

## 蓝图内容指导判断，runtime 负责执行

蓝图必须告诉未来 Author 哪些证据和区分重要，但不能成为第二套调度或重试协议。将未来目标流程与写作调用机制分开，保留公开 writer 权威，并允许不同项目证据形成不同的有效文档。

## 区别刷新事实与持久意图

工具映射可能变错，而项目已接受流程仍然合理。统一的重写或保留规则，要么保留过时事实，要么抹掉有效决定。明确按内容选择刷新偏好，能同时保护准确性与项目所有权。

## 交接不完整仍可能允许发现

未来 Author 负责在获准访问内发现并确认可恢复的项目证据。把每项未提供事实都视为停止理由，会将有用调查变成反复询问用户；完成发现后仍无依据的重要事实，才是真正的停止条件。
