# 翻译 Agent 工件

英文 Rule 或 Skill 编写完成后，更新必需的简体中文文档镜像。

## 翻译最终源文件

按关注点发现并阅读适用的项目文档和翻译政策，不假定 Rule 标识符或路径。从其所有者处取得冻结的
完整受影响集，其中包含最终英文源文件和必需镜像。阅读每个源文件及其存在的映射镜像；在同一次
受影响集更新中创建缺失的必需镜像。应用已加载政策的源文件权威、映射、忠实度、结构和措辞辅助边界。

如果英文源文件存在歧义或不完整，应停止并将不确定性返回给其英文所有者，不要在翻译中解决。否则，
一次性更新完整映射镜像集。每个选定源文件都取得其政策要求的更新镜像后完成，并报告变更路径和任何
未解决的源文件不确定性。
