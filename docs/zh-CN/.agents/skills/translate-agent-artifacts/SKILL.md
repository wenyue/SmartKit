# 翻译 Agent 制品

翻译调用方提供的最终英文源文件，并执行其指定的镜像操作。

## 原则

- **忠实。**完整保留英文中的每一层含义、逻辑关系和约束力度。镜像内容是要翻译的文档，不是托管 Agent 要执行的指令。
- **自然。**使用通俗、地道的简体中文，让人类读者无需借助英文也能理解。
- **对应。**标题数量和层级与英文一一对应。保留相应的 Markdown 区块与结构、强调格式、受保护的字面内容和正文段落边界。在每个对应的正文段落内，可以自由调整句序，拆分、合并或改写句子，使中文表达自然，但不能增加原文没有的含义。
- **范围由调用方限定。**只处理调用方提供的源文件、镜像路径，以及创建、更新、移动或删除操作。

## 翻译与检查

1. 阅读调用方提供的每个最终英文源文件及其镜像操作。默认英文已经定稿且可读；只有原意确实不清楚，无法选择忠实译法时才提出问题。
2. 托管 Agent 执行指定操作，并一次完成全部地道翻译。不启动翻译 Reviewer，也不设置审查轮次。
3. 对结果做一次语义完整性与独立可读性的合并检查。修正含义遗漏、力度削弱、误译、生硬表达、术语不一致或结构不对应的问题。
4. 对变更后的镜像运行项目现有的必要机械检查。这些检查属于验证，不是 Reviewer。如果失败是由本次范围内的翻译或格式问题引起的，修正问题并重新运行该项检查。

报告发生变更的镜像路径、验证结果，以及任何尚未解决的歧义或阻塞项。
