# 自托管源权威

为每个适用的 SmartKit 或项目 Rule、Skill 单独选择权威副本。来源选择不替代其他产物的职责。

## 优先使用对应检出源

对应源存在时，使用当前检出中的产物源：

| 产物 | 检出源 |
| --- | --- |
| SmartKit Rule | `rules/*.md` |
| 项目 Rule | `.agents/rules/**` |
| 插件清单公开的 SmartKit Skill | `skills/<name>/**` |
| 项目 Skill | `.agents/skills/**` |

用户未限定副本的 SmartKit Rule 或 Skill 引用，解析到该源。明确引用另一副本时，则选择所指副本。

选择检出源中的 Skill 时，完整阅读其 `SKILL.md`，并从同一源树读取所有必需参考资源。

## 区分不存在与读取失败

只有对应检出源不存在时，才使用已安装、注入、打包或缓存的副本作为后备。读取失败不能证明不存在：已有源可能不可访问或无法读取。

如果必需内容仍不可用，报告缺口，并按核心治理的加载要求停止依赖工作。

## 保持归属与组合不变

来源选择不改变通常的适用性、Rule 优先级和 Skill 组合。保留每个独立适用的 Rule 和 Skill；选择一个副本，不替代另一个不同产物。

`.agents/rules/project-policy.md` 仍是规范所有权、契约与暴露、翻译和验证的唯一负责方。
