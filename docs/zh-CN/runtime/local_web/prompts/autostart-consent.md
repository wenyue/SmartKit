A．启用，并保存选择。

➡️ 推荐 A，减少服务未运行造成的本地链接不可用。

检查时，当前用户尚未选择是否启用登录自启动。进入本步骤时，通过当前加载的 local_web 入口运行 `autostart status`。提供的入口是 {entry}；插件更新或重启后，从已加载插件的 local_web 资源重新解析入口。如果已经保存布尔选择，跳过此问题；对意外的注册状态只作报告，不静默修复。如果不支持登录自启动，报告该情况并结束本步骤，不请求提权或系统级注册。状态检查失败时，本步骤仍未完成。

如果支持登录自启动且仍未作出选择，只提供 A/B，没有稍后选项，也没有默认选项。A 授权执行 `autostart enable`；B 授权执行 `autostart disable`，以保存拒绝选择。使用当前 Python 解释器，仅执行用户选中的动作。不注册系统级启动、不提权、不启用 lingering，也不修改其他用户的配置。选择和操作系统启动项按用户隔离；检测使用现有按项目、Harness 区分的每日检查关口，不增加全局关口。

核验返回的选择和实际注册状态。成功启用要求选择为 true 且注册状态为 installed；成功关闭要求选择为 false 且注册状态为 disabled。仅保存选择不足以证明成功。B 必须持久化后才能继续。失败时报告原因，保留选择和部分文件所有权，以便明确重试；操作仍保持未完成。选择经核验完成后，将控制权交回检查流程。
