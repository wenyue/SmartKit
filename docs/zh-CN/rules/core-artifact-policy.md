# 产物策略

按所有者和生命周期选择存储位置，再仅发布应当公开的内容。

## 区分临时产物与持久工作

任务的可写临时工作数据保存在任务、项目或操作系统管理的临时存储中，并明确清理所有者。包缓存、下载缓存和构建缓存保存在各自工具管理的存储位置，并遵循工具的生命周期。

将选定的可丢弃输出或证据捕获到 SmartKit 的共享产物缓存中，除非用户、项目或适用 Skill 指定了其他位置或生命周期。通过已安装的工具创建每个不可变文件组，工具会执行其帮助中定义的字节数和文件数量限制。保持已捕获的内容及目录结构不变，文件发生变化或需要增加文件时，捕获一个新文件组。保留期可按产物配置，默认七天。

没有指定目录并不意味着输出可以丢弃。源文件修改、规范记录以及需要保留的唯一副本，均按各自的所有者契约保存。需要更早删除的敏感采集材料，仍由其所有者使用私有存储和删除生命周期管理。

## 使用已安装的共享工具

从已加载安装的 `SmartKit plugin resources` 元数据提供的绝对路径解析 `local_web`，不依赖目标项目的工作目录。在捕获文件、发布产物或生成本地差异链接前，阅读其命令接口。

```bash
python "<local_web>" --help
```

将占位符替换为提供的路径。统一 CLI 的帮助定义操作输入、命令和结果。完整的 SmartKit 插件和 Python 3.8+ 是前提。

如果缺少必要元数据、工具或 Python 能力，报告缺失的前提。在通过受支持的已安装工具路径成功完成操作前，将依赖它的输出保持为未完成状态。对于保留的产物，只有发布成功后才能报告已交付 URL。

## 显式发布

默认将缓存保持私有。创建产物既不会启动 HTTP 服务，也不会返回 URL。

当网页展示合适且已获授权时，声明要公开的文件，并通过网页工具发布保留的产物。使用工具返回的当前 URL，不声明私有文件。如果功能工具已经返回捕获的产物或 URL，直接复用，不再缓存或发布一次。
