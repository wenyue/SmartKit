# 产物策略

根据产物的生命周期选择存储位置，再仅发布应当公开的内容。

## 区分临时产物与持久工作

一次性临时文件使用 SmartKit 的共享产物缓存，除非用户、项目或适用 Skill 指定了其他位置或生命周期。保留期可按产物配置，默认七天。

没有指定目录并不意味着输出可以丢弃。源文件修改、规范记录以及需要保留的唯一副本，均按各自的所有者契约保存。需要更早删除的敏感采集材料，仍由其所有者使用私有存储和删除生命周期管理。

## 使用已安装的共享工具

从已加载安装的 `SmartKit plugin resources` 元数据提供的绝对路径解析 `local_web`，不依赖目标项目的工作目录。在使用临时存储、发布产物或生成本地差异链接前，阅读其命令接口：

```bash
python "<local_web>" --help
```

将占位符替换为提供的路径。统一 CLI 的帮助定义操作输入、命令和结果；完整的 SmartKit 插件和 Python 3.8+ 是前提。

如果缺少必要元数据、工具或 Python 能力，报告缺失的前提，并将依赖它的输出保留为未完成状态。任意项目目录不能替代该工具；未能发布也不能报告为已交付 URL。

## 显式发布

默认将缓存保持私有。创建产物既不会启动 HTTP 服务，也不会返回 URL。

当网页展示合适且已获授权时，声明要公开的文件，并通过网页工具发布保留的产物。使用工具返回的当前 URL，不声明私有文件。如果功能工具已经返回捕获的产物或 URL，直接复用，不再缓存或发布一次。
