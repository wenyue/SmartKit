# 产物政策

## 存储一次性临时产物

一次性临时文件使用 SmartKit 共享产物缓存，除非用户、项目或适用的 Skill 指定了输出位置或生命周期。每个产物都可以配置保留时长，默认七天。未指定目录本身并不意味着输出可以到期丢弃：源文件改动、规范记录和需要保留的唯一副本，仍须按各自所有者的契约保存。需要更早删除的敏感采集材料，继续遵循其所有者的私有存储和删除生命周期。

## 使用共享工具

从已加载安装位置提供的 `SmartKit plugin resources` 元数据中，使用 `local_web` 的绝对路径定位共享工具，与目标项目的工作目录无关。使用临时存储、发布产物或生成本地 diff 链接前，将提供的路径代入 `python "<local_web>" --help` 并读取帮助。操作的输入、命令和结果由统一 CLI 帮助说明。需要完整的 SmartKit 插件和 Python 3.8 或更高版本。

必要的资源元数据、工具或 Python 能力不可用时，报告缺失的前提条件，并将依赖它的输出保留为未完成。不悄悄改用任意项目目录，也不宣称 URL 已交付。

## 显式发布保留的产物

默认私有缓存；仅创建缓存不会启动 HTTP 服务，也不会返回 URL。网页展示适用且已获授权时，明确声明拟公开的文件，再通过 Web 工具发布保留的产物，并使用它返回的当前 URL。将私有文件排除在公开声明之外。功能工具已经返回捕获的产物或 URL 时，复用该结果，不重复缓存或发布。
