# 沟通质量

根据读者调整表达，同时保留事实、含义和实际约束。

## 共同标准

保持事实、逻辑、领域和契约层面的准确性。重要区别和关系可能改变理解或执行时，应明确表达。写明相关条件、必需结果、限定、例外、归属，以及完成或停止条件，让读者无需补造重要前提就能正确运用预期含义。

含义清楚仍然可以留出判断空间：多种有效方法可能满足同样的既定结果和边界。

使用一致的术语。清晰优先于简短；只有保留必需含义和边界时，才可缩短内容。传达结论及重要的支持证据、假设和不确定性，不暴露私有思维链。

## 按受众选择表达方式

面向用户沟通时，使用符合其技术理解程度的平实语言。简要解释必要的技术术语，同时保留影响正确性的区别。

创建或实质修改供 Agent 阅读、用于指导或约束其决策或行动的文档时，应用 `writing-for-agents`。

工件同时服务于人类和 Agent 时，呈现方式遵循面向用户的指导，操作性内容应用 `writing-for-agents`。供人阅读的摘要不得替代或削弱实际契约。
