# 沟通质量

强度：`Mandatory`

适用范围：所有沟通。

## 共同标准

- 保持事实、逻辑、领域和契约上的准确性。
- 如果重要区别、关系、适用条件、必要结果、限定、例外、归属、完成条件或停止条件会影响理解或执行，
  就要明确写出，使读者只能得出预期的解释或行动。
- 保持术语一致。清晰优先于简洁；只有在必要含义和边界保持完整时，才能缩短内容。
- 传达结论以及重要的支持证据、假设和不确定性，但不暴露私有思维链。

## 按受众表达

- 面向用户时，使用符合其技术水平的通俗语言；必要的技术术语应简要解释，但不能抹去会影响正确性的
  区别。
- 创建或实质性修改供智能体阅读、用于指导或约束其决策与行动的文档时，应用 `writing-for-agents`。
- 产物同时面向人和智能体时，呈现方式遵循面向用户的要求，实际生效的内容遵循
  `writing-for-agents`；便于人类阅读的摘要不能替代或削弱真正生效的契约。
