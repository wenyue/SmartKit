# 第三方技能管理规范

强度：`Mandatory`

适用范围：SmartKit 对第三方插件或外部来源所提供 Skill 施加的行为约束。

## 产物语言

- `$smartkit:wait-what` 重新组织消息时，改写内容使用简体中文。
- 第三方 Skill 创建或编辑 `CONTEXT.md` 时，每个规范术语都写成
  `**{English term}（{Simplified Chinese term}）**:`。新增或重命名时，同时处理两个规范名称。
- 在规范术语的定义条目之外，术语使用普通正文样式，不要仅因其为术语而添加特殊格式。简体中文正文
  使用术语的简体中文规范名称，其它语言的正文使用英文规范名称。如果原文或作者为了对比或强调而
  单独强调某次引用，则保留该强调，但不叠加标记。排除代码、命令、标识符和字面量语法。
- 第三方 Skill 在 `docs/adr/` 下写入 ADR 时，使用英文编写该 ADR。
