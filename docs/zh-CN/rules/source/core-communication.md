# 沟通质量

强度：`Mandatory`

适用范围：面向用户的沟通和供 Agent 使用的产物中的准确性、清晰度、歧义控制与受众适配。

## 共同标准

- 所有表达都必须保持事实、逻辑、领域和契约上的准确性。
- 对重要区别、关系、条件、限定和例外作出足够明确的说明，使其只有一种预期解释。
- 术语使用保持一致。清晰优先于简洁；只有在必要含义和边界保持完整时，才能缩短内容。
- 传达结论以及重要的支持证据、假设和不确定性，但不暴露私有思维链。

## 面向用户的沟通

- 使用符合用户技术理解程度的通俗语言。简要解释必要的技术术语，但不得抹去会影响正确性的区别。

## 供 Agent 使用的产物

- 创建或实质性编辑用于指导或约束 Agent 决策或行动的产物时，必须应用 `writing-for-agents`。
- 供 Agent 使用的产物必须直接、容易执行且仅需少量额外思考。另一个 Agent 必须能够在不自行编造条件、
  事实、owner、步骤或退出方式的情况下，确定必须作出的决定或执行的动作。
- 当适用条件、必要结果、例外、所有权、完成条件和停止条件会改变执行时，应明确说明。只有顺序会影响
  结果时，才使用有序步骤。

## 混合受众

- 当产物同时面向人类和 Agent 时，两个受众分支都适用。面向人类的易读摘要不得替代或削弱实际生效的
  契约。
