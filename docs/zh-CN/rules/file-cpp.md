# C++ 指引

强度：`Default`

适用范围：工具配置之外的 C++ 归属、接口、失败契约和并发约束。

## 接口与归属

- 保持公共接口精简，并维持既有 ABI、FFI 和操作系统平台边界。
- 行为应留在负责它的所有者中；只有一组相关输入已经形成稳定概念时，才引入选项类型。
- 优先使用 RAII 和值语义。
- 优先使用智能指针，不要使用负责所有权的裸指针。

## 失败与并发

- 把预期内的失败纳入返回契约；只有周边边界也认为某种失败属于异常时，才使用异常处理。
- 由一个明确的所有者负责共享可变状态，并使用满足需求的最小同步原语。
- 跨原生回调维持清理、取消和线程亲和性要求。

## 工具归属

- 代码格式和命名交给仓库的格式化工具、编译器和静态分析配置。
- 在原生资源归属、失败处理或 ABI 行为可能退化的边界上测试实际行为。
