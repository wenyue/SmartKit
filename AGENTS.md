## Project rules

Apply SmartKit plugin Rules for shared strength and precedence. Keep project Rule policy in the
files listed below.

Before starting a task, ensure the complete applicable content of every Rule below is available.
Reuse content already in context while it remains current. Read missing content, including after
compaction, and refresh affected content when there is evidence of a change.
